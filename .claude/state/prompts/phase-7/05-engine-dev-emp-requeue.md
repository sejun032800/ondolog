## 목표

EMP 공식을 갱신된 17-3에 맞추고, 규준집단을 재열거해
`norm-synthetic-v2.json`을 생성한다.

## 배경 (읽고 시작할 것)

`#2`의 전수 열거에서 에니어그램 코어 1·2·6이 구조적으로 하위에 몰리는 것이
관측됐다. 원인은 호나이 삼분법 세 그룹 중 순응형(1·2·6)에만 대응하는 스탯이
없어 이 세 코어가 보너스를 하나만 받았기 때문이다.

17-3이 수정돼 **순응형 → EMP 보너스**가 신설됐다. 이 작업은 그 수정을 코드에
반영하고, 규준집단을 다시 산출한다.

**규준집단은 채점 로직의 산출물이므로 공식이 바뀌면 무효가 된다.** `#2`에서
만든 드리프트 감지 테스트가 이번에 깨질 것이고, **그게 그 테스트가 설계된
목적이다.**

## 1부 — EMP 공식 갱신

### 착수 전 보고

1. `src/engine/leagueStats.ts`의 **현재 EMP 공식**을 그대로 보고한다
2. 17-3의 **갱신된 EMP 공식**을 그대로 보고한다
3. **`computeSixStats`를 소비하는 다른 모듈이 있는지** 조사해 보고한다
   (`dnaScore.ts` 등이 6각 스탯을 쓰고 있다면 그쪽 엔진 버전도 영향을 받는다)

### 구현

- 17-3의 공식을 그대로 반영한다. **가중치를 조정하거나 반올림하지 않는다**
- 호나이 삼분법 그룹 판정은 **기존 로직을 재사용한다.** 주장형·후퇴형 판정이
  이미 코드에 있을 것이므로, 순응형만 새로 옮겨 적는 일이 없도록 한다
- `LEAGUE_STATS_ENGINE_VERSION`을 **올린다.** 공식이 바뀌었으므로 필수다.
  올린 값과 근거를 보고한다

### 기존 테스트 — 이번에 한해 수정이 허용된다

**EMP 값을 검증하던 기존 테스트는 공식 변경으로 정당하게 깨진다.**
이 경우에 한해 기댓값 갱신이 허용된다.

- [ ] **깨진 테스트를 하나씩 열거해 보고한다** — 파일·테스트명·기존 기댓값·새 기댓값
- [ ] 새 기댓값은 **갱신된 공식으로 손계산해 도출한다.** 코드 출력을 그대로
      붙여넣지 않는다 — 그러면 테스트가 구현을 검증하는 게 아니라 복사하게 된다
- [ ] **EMP와 무관하게 깨진 테스트가 있으면 고치지 말고 멈추고 보고한다.**
      그건 이 작업이 의도하지 않은 파급이다

## 2부 — 규준집단 재열거

### 새 버전 파일을 추가한다

- 출력: `src/engine/data/norm-synthetic-v2.json`
- **`norm-synthetic-v1.json`을 수정하거나 삭제하지 않는다.** 과거 발행물의
  재현에 필요하다(Part 10-8-3)
- `version`은 `synthetic-v2`
- `engineVersions` 맵에 **올린 `leagueStats` 버전**이 반영돼야 한다

### 기존 열거 함수를 그대로 쓴다

`#2`에서 만든 열거 순수 함수와 생성 스크립트를 재사용한다.
공식이 바뀌었으므로 **같은 코드가 다른 결과를 낸다** — 그것이 정상이다.

**열거 로직을 다시 짜지 않는다.** 채점 함수도 재구현하지 않는다.

### 드리프트 감지 테스트 — 이번에 한해 수정이 허용된다

이 테스트는 **v1을 대조하도록** 쓰여 있어 반드시 깨진다. 설계대로다.

- [ ] 대조 대상을 **v2로 갱신**한다
- [ ] 갱신 후에도 **열거를 실제로 재호출**해 비교하는 형태를 유지한다.
      파일끼리 비교하거나 샘플링하는 형태로 바꾸지 않는다
- [ ] v1을 대조하는 테스트를 **남길 필요는 없다** — v1은 데이터로 보존되지만,
      현재 코드로 v1이 재현되지 않는 것이 정상이기 때문이다

## 3부 — 점검 수치 산출 (판단하지 말 것)

`#2`와 **동일한 형식**으로 산출해 보고한다. 비교가 목적이므로 형식이 같아야 한다.

### ① 에니어그램 코어 9종별 합성값 분포

코어 1~9 각각의 평균·표준편차·최소·최대·표본 수.

추가로 아래 둘을 함께 보고한다.

- **코어 간 평균의 최대−최소 폭** (`#2`에서는 5.75였다)
- **평균 기준 오름차순 정렬한 코어 순위** (1위=최저부터 9위=최고까지)

### ② 분산 지배 점검

스탯 6종의 평균·표준편차. 합성값 분포의 평균·표준편차.

> **두 점검 모두 판단하지 말 것.** 수치만 보고한다.
>
> **결과가 기대에 못 미쳐 보여도 가중치를 조정하지 말 것.** 17-3의 값이
> 확정 사항이며, 결과 해석과 추가 조정 여부는 마스터 PM 결정이다.

## 완료 기준

- 호나이 그룹 판정 로직을 재사용했다
- `LEAGUE_STATS_ENGINE_VERSION`이 올랐다
- `norm-synthetic-v2.json`이 생성됐고 `version`이 `synthetic-v2`다
- **`norm-synthetic-v1.json`이 변경되지 않았다**
- v2의 `engineVersions`에 올린 버전이 반영됐다
- 배열 7개(합성값 1 + 스탯 6) 각각의 길이가 정확히 **3,888**이다
- **재실행 시 바이트 단위로 동일한 v2 파일이 생성된다**
- 드리프트 감지 테스트가 v2를 대조하며 **열거를 실제로 재호출**한다
- 깨진 기존 테스트가 **EMP 관련 + 드리프트 테스트로 한정**되며, 각각
  파일·테스트명·기존 기댓값·새 기댓값이 보고됐다
- 코어 9종 분포와 순위, 분산 지배 수치가 `#2`와 같은 형식으로 보고됐다
- `npx tsc --noEmit -p .` 통과 (**0 에러**)
- `grep -rn "UNRESOLVED(" src/engine/ --include=*.ts | grep -v "^\s*\*"`가
  **2건** — 정의 1건 + `temperature.activityScore` 소비 1건. 늘지도 줄지도 않는다
