기기에 저장하는 **모든 범주**를 표로 정리합니다. 열은 다음과 같습니다.

| 범주 | 저장 위치(localStorage · IndexedDB · 파일) | 담는 것 | 지금 모양 검사 | 깨지면 지금 어떻게 되나 | 사용자가 쓴 것인가(대기열) |

- 최소 대상: main · chat · feed · sky · 글 대기열(`textQueueHub`) · 사진 대기열(`photoQueueHub` — 파일 포함) · 오류 건수(80-) · 푸시 등록 표시 · 서랍 · 기기 id · 알림 안내 표시(F1 · 닉네임) · 마지막 탭 · 그 밖에 찾은 것 전부

## 1단계 — 공통 규칙 (R117-2)

| 규칙 | 내용 |
|---|---|
| 모양 버전 | 범주마다 **버전 번호**를 붙여 저장 |
| 읽을 때 검사 | 버전 · 모양(필수 칸 · 타입) 확인. 가벼운 손 검사(새 패키지 0) |
| 버림(일반 범주) | 깨짐 · 옛 버전 → **그 범주만** 버리고 서버에서 다시 읽기 · `cache_fail` **1회**(같은 원인 반복 기록 0) · 화면은 자리 표시 → 정상 |
| 대기열(사용자가 쓴 것) | **버리지 않음.** 옛 모양 → 새 모양 **변환**. 변환 불가면 **원본을 그대로 보존**(별도 보관 칸) + `cache_fail` 기록 · 보내기 시도에서 빼되 지우지 않음 · 사진 파일은 절대 지우지 않음 |
| RenderGuard [다시 시도] | 그 화면이 쓰는 **깨진 범주를 먼저 비운 뒤** 다시 그림(대기열은 비우지 않음) → 다시 깨지는 반복 0 |
| 앱 시작 | 시작 때 범주들을 한 번 훑어 깨진 것을 미리 정리(시작이 멈추지 않게 — 실패해도 진행) |
| 삭제 규칙 회귀 0 | 로그아웃 · 탈퇴 요청 · 해제 요청 · 해제 유예/완료 · 계정 전환 때 지우는 규칙(76- · 78- · 76-i · 80-) 그대로. 보존된 대기열 원본도 같은 규칙으로 지움(계정이 바뀌면 남기지 않음) |

- 업데이트에서 모양을 바꿀 때 지킬 것을 결정 기록에 한 줄: "범주 모양을 바꾸면 버전을 올리고, 대기열은 변환 함수를 함께 둔다"

## 2단계 — 시험

- **범주마다**(0단계 표 전부):
  - 깨진 값(JSON 아님 · 칸 빠짐 · 타입 다름)
  - 옛 버전 값
  - → 화면 정상 · 서버에서 다시 채움 · `cache_fail` 1회
- **대기열**:
  - 옛 모양 → 변환되어 정상 전송
  - 변환 불가 → 원본 보존 · 보내기에서 빠짐 · 지워지지 않음 · 사진 파일 남음
- RenderGuard [다시 시도] → 깨진 범주 비움 → 정상 화면(80-에서 관찰한 반복 깨짐 0)
- 로그아웃 · 계정 전환 → 보존된 원본까지 지움
- **스모크**: 깨진 저장값 1화면 추가(피드 외 하나 더 — 예: 메인) · 대체 화면 없이 바로 정상, 또는 [다시 시도] 한 번에 정상
- `ensureDate` "**지운 뒤 새 행**"(R113-1): `__tests__/services/`의 기존 가짜 저장소 시험에 한 건 — 숨긴 날짜 행이 없어진 뒤 같은 날 기록 → 새 행 생성 · AI 칸 빔
