## 범위 (PM) — 둘

### 1. 규칙 F 수집을 git이 추적하는 모든 파일로

- 수집은 **git이 추적하는 모든 파일 — 최상위 포함**. 디렉터리 목록을 두지 않는다
- git이 없으면 파일 시스템을 돌되 **`node_modules/`·`.git/`은 뺀다**
- basename만 본다(그대로). 합성 입력 테스트는 그대로 두고, **저장소 실제 파일이 통과**한다
- 최상위 파일(`CLAUDE.md`·`package.json` 등)이 **수집에 들어갔는지** 테스트로 확인한다

### 2. 텍스트 없는 HTTP 2xx 응답의 사유

- **지금 구현이 어느 사유로 기록하는지 먼저 확인해 보고**한다
- 사유는 **`schema_invalid`**여야 한다(r47). 대기는 없고 예산은 쓴다(r46·r47 그대로)
- 지금이 `schema_invalid`가 아니면 그렇게 고치고, **파이프라인 전체를 지나 저장 함수가
  `schema_invalid`로 불리는** 테스트로 보인다
