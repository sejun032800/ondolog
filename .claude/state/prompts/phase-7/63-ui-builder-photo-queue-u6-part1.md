사람이 이 묶음만 따로 먼저 커밋한다. 보고에 이 묶음의 파일 목록을 따로 붙인다.

| # | 할 일 |
|---|---|
| a | **사진 영속 큐**(R37-2) — 사진 메시지 · 스토리 둘 다. **`package.json`에 `expo-file-system`이 없으면 a는 시작하지 않고 보고**하고 b·c·§1로 넘어간다. 있으면: ① 고른 사진을 앱 문서 폴더에 복사 ② 큐 항목(클라이언트 id · 종류 · 복사본 경로)을 기기에 저장 ③ 성공하면 큐 항목과 복사본을 지운다 ④ 앱을 다시 열면 남은 항목을 이어서 보낸다. 표시는 텍스트 큐와 같은 F05 |

| b | **실시간 메우기**(R37-3) — 구독이 `SUBSCRIBED`가 될 때 · 다시 연결될 때 · 앱이 앞으로 돌아올 때(AppState `active`), **마지막으로 받은 메시지 이후를 조회해 합친다.** 같은 메시지가 실시간과 조회로 두 번 와도 화면에는 하나. 이미 이렇게 돼 있으면 고치지 말고 파일·줄만 보고 |
