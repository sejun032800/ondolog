### ① 지우는 길 정하기

- 묶음 ①: 기존 `resetTestAccount.ts` 커플 모드로 됩니다. 이메일 둘을 쓰고, 발행 호가 없으면 `--with-issues` 없이도 됩니다. 있는지 없는지는 미리 보기가 알려 줍니다.

  2. 있다면 `resetTestAccount.ts`(허용 목록 · `project=` 잠금 · `--with-issues`)로 지울 수 있는가.
  3. 없거나 맞지 않는다면 **가장 작은 추가**가 무엇인가.
- 추가가 필요하면 다음 조건으로 만듭니다.
  - 기존 초기화 코어를 그대로 씁니다. 새 삭제 로직은 0입니다.

  - 미리 보기가 기본이고, 실제 삭제는 `--apply`일 때만 합니다.
  - 목록 밖 커플이거나 별명에 `test`가 없는 사용자가 하나라도 있으면 **전체 거부**합니다(아무것도 조회 · 삭제하지 않음).

  - 시험(원격 없음): 목록 밖 거부 · 별명 잠금 · 미리 보기에 쓰기 0 · `project=` 거부.
