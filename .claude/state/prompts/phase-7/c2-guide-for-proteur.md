### 1-3. 별 모양 · 반짝임 끔 · 유성 (한 폰이면 충분 — V40 권장)

1. 하늘 첫 화면에서 본다:
   - 큰 별은 긴 빛살 + 장밋빛 후광, 중간 별은 짧은 십자 빛살, 작은 별은 점이에요. 빛살과 후광은 천천히 숨 쉬듯 커졌다 작아져요.
   - 기념일 별이 있으면 장밋빛 점선 고리가 천천히(1분에 한 바퀴) 돌아요. 기념일이 없으면 "해당 없음"으로 적어요.
   - 달은 초승달이고 둘레가 은은하게 밝아졌다 어두워져요.
2. 설정 → OUR SKY → **"별 반짝임"**을 꺼요. 하늘로 돌아가서 본다:
   - 정상: 별 숨 · 배경 작은 별 · 고리 회전 · 달 후광이 **모두 멈춰요.**
3. 반짝임을 끈 채로 설정 → OUR SKY 맨 아래 **"유성 미리 보기 · 시험판"**을 눌러요.
   - 정상: 유성은 **그대로 떨어져요.** 머리 뒤로 꼬리가 길어지고 작은 빛 조각이 떨어지는 새 모양이에요.
   - 3초 안에 누르면 떨어진 말 화면(C03)이 나와요.
4. **C03 맨 아래 출처 줄의 시각**이 **"밤 9시 30분"** 꼴(앞에 새벽 · 아침 · 낮 · 저녁 · 밤 중 하나 + 12시간제)인지 봐요. "21:30" 꼴이면 이상이에요.
5. "별 반짝임"을 **다시 켜요.**

## 3부 — 커플 모드 초기화 (두 폰 커플 두 계정 · 발행 호까지)

이 부분은 51- 원문 순서(R122-3 ③)의 "커플 모드 초기화"예요. **되돌릴 수 없어요.** 미리 보기 결과를 PE가 확인한 뒤에만 실제로 지워요.

### 3-0. 두 폰에서 앱 지우기

1. 폰 A: 바탕 화면의 **온도록 아이콘을 길게 누르기 → [제거] 또는 [삭제] → 확인**
2. 폰 B: 같은 방법으로 지워요.
   - 이렇게 해야 폰에 남은 옛 커플 기록이 새 가입과 섞이지 않아요.

### 3-1. 창 준비 · 키 넣기 (PowerShell 새 창 · 저장소 맨 위)

1. 시작 메뉴에서 PowerShell을 **새로** 열어요.

        cd "C:\Users\sejun\OneDrive\바탕 화면\ONDOLOG\ondolog"

2. 접속 값 두 개를 보이지 않게 넣어요. 줄마다 입력 칸이 나오면 **마우스 오른쪽 클릭**으로 붙여 넣고 Enter를 눌러요.

        $env:ONDOLOG_SUPABASE_URL = [Net.NetworkCredential]::new('', (Read-Host -AsSecureString)).Password

   → 여기에는 **개발 프로젝트 주소**를 넣어요. `https://…supabase.co` 꼴이고 `/rest/v1/`가 붙지 않은 것이에요.

        $env:ONDOLOG_SUPABASE_SERVICE_ROLE_KEY = [Net.NetworkCredential]::new('', (Read-Host -AsSecureString)).Password

   → 여기에는 운영용 secret key **`ops_2026_11`**을 넣어요.

3. 확인 세 줄이 모두 **True**여야 진행해요.

        $env:ONDOLOG_SUPABASE_SERVICE_ROLE_KEY.StartsWith('sb_secret_')

        $env:ONDOLOG_SUPABASE_URL.StartsWith('https://')

        $env:ONDOLOG_SUPABASE_URL.EndsWith('.supabase.co')

   - 셋째 줄이 False면 주소 끝에 무언가 붙은 거예요. 아래 한 줄을 실행하고 셋째 줄을 다시 확인해요.

            $env:ONDOLOG_SUPABASE_URL = ([Uri]$env:ONDOLOG_SUPABASE_URL).GetLeftPart('Authority')

4. 네트워크 허용 범위와 허용 목록 위치를 변수에 담아요. 화면에는 아무것도 안 나와요.

        $h = ([Uri]$env:ONDOLOG_SUPABASE_URL).Host

        $al = Join-Path $env:USERPROFILE '.ondolog\reset-allowlist.txt'

        Test-Path $al

   → **True**여야 해요(51-③ 때 만든 허용 목록 파일이에요).

5. 두 시험 계정의 카카오 이메일을 변수에 담아요. 이메일이 명령 기록에 남지 않게 하려는 거예요.

        $e1 = Read-Host '폰 A 카카오 이메일'

        $e2 = Read-Host '폰 B 카카오 이메일'

### 3-2. 미리 보기 (아무것도 지우지 않음)

    deno run --no-check --no-lock --unstable-sloppy-imports --config supabase/functions/deno.json --allow-env=ONDOLOG_SUPABASE_URL,ONDOLOG_SUPABASE_SERVICE_ROLE_KEY,ONDOLOG_RESET_ALLOWLIST,USERPROFILE,HOME --allow-net=$h --allow-read="supabase/.temp/linked-project.json,$al" scripts/ops/resetTestAccount.ts $e1 $e2 --with-issues

- 정상: 지울 것의 종류와 건수가 나와요(계정 2 · 커플 1 · 호 1 · 기록 · 사진 · 메시지 등).
- "거부"가 나오면 그 **문장만** 보내 주세요. 문구에는 이메일과 ref가 나오지 않게 되어 있어요.
- **여기서 멈추고 PE에게 보내요.** 보낼 것은 **종류와 건수 줄만**이에요. 이메일이 보이는 줄이 있으면 그 부분을 지우고 보내요.
- 창은 닫지 말고 그대로 둬요.

### 3-3. 실제 삭제 (PE가 "진행"이라고 한 뒤에만)

    deno run --no-check --no-lock --unstable-sloppy-imports --config supabase/functions/deno.json --allow-env=ONDOLOG_SUPABASE_URL,ONDOLOG_SUPABASE_SERVICE_ROLE_KEY,ONDOLOG_RESET_ALLOWLIST,USERPROFILE,HOME --allow-net=$h --allow-read="supabase/.temp/linked-project.json,$al" scripts/ops/resetTestAccount.ts $e1 $e2 --with-issues --apply

- 정상: 지운 건수가 미리 보기와 같고, 실패는 0이에요. 그 줄만 보내 주세요.

### 3-4. 창 닫기 · 확인

1. 이 PowerShell 창을 **닫아요**(창 안에 키가 남아 있어요).
2. 시작 메뉴에서 새 PowerShell을 열고 두 줄을 실행해요.

        [bool]$env:ONDOLOG_SUPABASE_SERVICE_ROLE_KEY

        [bool]$env:ONDOLOG_SUPABASE_URL

   → 둘 다 **False**여야 해요.

## 4부 — 새 가입 · 연결 전 화면 · 연결 (51- ② ~ ⑥ 중 남은 것)

### 4-0. 두 폰에 새로 설치

1-0의 Android Studio에서 **S21 ▶ Run**, **V40 ▶ Run**을 눌러요. 이번에는 앱을 지운 뒤라 새로 설치돼요.

### 4-1. 온보딩 — B20 (폰 A 먼저, 다음 폰 B)

1. 앱을 열어요 → 스플래시 → 기본정보 → MBTI → 5문항 → 결과 → 동의(v1.2) 순서로 끝까지 가요.
2. **비로그인 구간 중간**(예: 5문항 중간)에 앱을 완전히 닫았다가 다시 열어요.
