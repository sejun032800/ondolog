## 1. 유성 미리 보기 — 두 폰 모두

1. 설정 → OUR SKY **맨 아래에 "유성 미리 보기 · 시험판"** 줄이 보이는지
2. 누르면 하늘 첫 화면으로 가고 **1초 안쪽에 유성이 오른쪽 위 → 왼쪽 아래로** 지나가는지
3. **지나가는 유성을 손가락으로 눌러서 잡을 수 있는지**(머리 근처 · 3초 안) → **떨어진 말(C03)** 화면이 열리는지
4. C03에서 **긴 글을 위아래로 밀어** 끝까지 읽히는지(스크롤이 부드럽게 · 글이 잘리지 않음) · ‹ 이전 말 / 다음 말 ›
5. **폰의 뒤로 가기**로 C03이 닫히는지(앱이 꺼지거나 메인으로 튀지 않고 하늘로)
6. 다시 미리 보기를 누르고 **일부러 놓치면** 유성이 사라지는지
7. 하늘에서 [둘러보기](C08)로 들어가면 거기서도 유성이 하나 지나가는지
8. **V40**: 2 · 7에서 유성이 **끊김 없이** 지나가는지(뚝뚝 끊기면 "8번 이상")

## 2. 애니메이션 삭제(움직임 줄이기)일 때 — 한 폰이면 충분(V40 권장)

9. 폰 설정 → 접근성 → **애니메이션 삭제 켜기**(삼성: 접근성 → 시인성 향상 → 애니메이션 삭제 / LG: 접근성 → 시각 → 애니메이션 끄기)
10. 온도록 → 설정 → 유성 미리 보기 → 하늘에서 **지나가는 유성 대신 제자리에서 빛나는 점**이 약 5초 보이는지 · 누르면 C03
11. 확인 뒤 **애니메이션 삭제를 원래대로 끄기**
