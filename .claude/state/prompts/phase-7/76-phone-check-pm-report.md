## 4. 보완 의견 (PE)

1. **F2가 가장 먼저.** 실제 커플이 첫 화면에서 보는 문장이 숫자와 모순됩니다("다음 날 나와요"인데 이미 44.7°). 76- 보고의 판단은 "시작 온도예요…는 활동분 0일 때만"이었는데, **다른 문장 "첫 온도는~"은 조건이 안 걸린 것**으로 보입니다. 활동분 > 0일 때 문구를 무엇으로 할지는 PM이 정해 주세요. PE 제안: 숨김(문구 0), 또는 "최근 14일의 대화와 기록으로 정해져요".
2. **F3 · F4 · F5는 한 원인**으로 봅니다. 76-의 기기 저장 장치가 채팅 메시지와 피드에는 걸렸고, **메인 요약과 채팅 머리 이름에는 안 걸렸습니다**. A1 원문(R98-1)은 이 셋을 모두 적었으므로 **A1은 "부분 통과"**로 정정합니다. 77-(하늘)도 같은 장치를 쓰기로 했으니, 77- 폰 확인 때 같이 확인하면 됩니다.
3. **F1**: 76- 보고는 "날짜는 기존 확인 흐름이 있어 됐다"였는데, 폰에서는 안내가 0프레임입니다. 원인 후보는 두 가지입니다. (a) 안내가 처음 연결 흐름에서만 뜸. (b) 이미 본 것으로 처리됨. 메인 세션이 원인을 판정해야 합니다. 닉네임 변경 안내는 `78-` 푸시로 넘어갔으니(R101-5), **날짜 변경 안내도 앱 안 표시로 고칠지, 78-로 합칠지** PM 결정이 필요합니다. PE 기준: 날짜는 D+와 기념일(77- C07 하늘 기념일 별)에 바로 영향이 있으므로 **앱 안 표시로 먼저**.
4. **묶는 법**: F1~F5는 작습니다. 77-이 돌고 있으므로 끼워 넣지 말고, **77- 끝난 뒤 `76-r`(작은 수정)로 `76-d` 하루 지우기와 같은 위임서**에 넣기를 권합니다. 다만 F2는 실제 커플 시작 전에 꼭 고쳐야 합니다.
5. **실제 커플 조건 영향**: 76-에서 실제 커플 조건이었던 것은 T(온도 v0) · M2 · A1 · A2 · C5입니다. **A2 통과 · T 값 통과 · A1 부분**입니다. A1의 핵심(오프라인 대화 유지)은 통과했으므로 PE는 **F2만 실제 커플 전 필수**, F3~F5는 권장으로 봅니다.
