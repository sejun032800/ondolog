## 목표

현재 코드로 DEF의 두 판(`v2`·`v3`) 공식을 재구성해, **반올림 전과 후의
평균**을 각각 낸다. 조회 전용이며 숫자 넷과 빈도표 하나를 낸다.

## 이 작업은 아무것도 바꾸지 않는다

**`src/` 아래 어떤 파일도 만들거나 고치지 않는다.** 규준집단 파일도
건드리지 않는다. 조회 전용 스크립트 하나와 그 출력이 전부다.

## 배경 (읽고 시작할 것)

규준집단 파일의 DEF 평균 차가, 애착 항의 평균 차에 가중치를 곱한 값과
어긋난다.

지금까지 파일·코드·축 정의·열거 경로를 전부 확인해 모두 정상임이
확인됐다. 남은 후보는 **저장 시 반올림**이다.

**반올림은 비선형이므로, 원소별 차분이 일정해도 반올림 후 평균 차는
보존되지 않는다.** 이 작업은 그것이 관측된 차이를 설명하는지 확인한다.

## 반올림 방식을 먼저 확인할 것

**저장 시 어떤 반올림이 적용되는지 코드에서 확인하고 보고하라.**

`scripts/norm/enumerate.ts`와 `scripts/norm/distribution.ts`에서
DEF 값이 배열에 들어가기까지 거치는 **모든 반올림 지점**을 찾아,
함수와 자리수를 보고한다.

**추측하지 말 것.** 실제 코드가 쓰는 함수와 자리수를 그대로 쓴다.

찾은 자리수와 파일에 저장된 DEF 값의 형태가 어긋나 보이면
**멈추고 보고한다.**

## 산출할 것 — 다섯

3,888 프로파일 각각에 대해 아래를 계산한다. 모든 입력은
**현재 경로에서 얻는다.**

```
N                = inferLoveType(...).big5.bigN
positiveBonus    = computeSixStats 내부와 같은 판정
A, V             = inferLoveType(...).attachAnxiety / .attachAvoidance
termV2           = computeAttachmentStability(A, V)     ← import해서 호출
termV3           = computeDefAnxietyStability(A)        ← import해서 호출

defV2raw = 0.4 × (100 − N) + 0.3 × positiveBonus + 0.3 × termV2
defV3raw = 0.4 × (100 − N) + 0.3 × positiveBonus + 0.3 × termV3
```

`defV3raw`를 **현재 `computeSixStats(...).def`와 대조해 보고할 것** —
재구성이 올바른지의 검산이다.

두 값이 어긋나면, **그 차이가 위에서 확인한 반올림으로 설명되는지**
확인해 보고한다.

- 반올림으로 설명된다 → **계속 진행한다.** 반올림이 `computeSixStats`
  안쪽에 있다는 뜻이고, 그것도 이 조사의 산출물이다
- 설명되지 않는다 → **멈추고 보고한다.** 재구성 자체가 틀린 것이다

### ① 반올림 없는 평균 둘

```
E[defV2raw]
E[defV3raw]
차 = E[defV3raw] − E[defV2raw]
```

**소수점 12자리 이상**으로 보고한다.

### ② 반올림 후 평균 둘

위에서 확인한 **저장과 동일한 반올림**을 각 프로파일 값에 적용한 뒤
평균을 낸다.

```
E[round(defV2raw)]
E[round(defV3raw)]
차
```

**소수점 12자리 이상**으로 보고한다.

### ③ 반올림 후 `v2`의 고유값과 빈도

`round(defV2raw)`의 서로 다른 값과 각 빈도를 **값 오름차순**으로 낸다.
빈도 합이 3,888인지 확인한다.

### ④ 반올림 후 `v3`의 고유값과 빈도

동일 형식.

### ⑤ 파일과의 대조

`norm-synthetic-v2.json`·`v3.json`의 `stats.def.sorted`에서 고유값과
빈도를 **직접 읽어** ③④와 값·빈도 단위로 대조한다.

```
값 집합이 일치하는가
각 값의 빈도가 일치하는가
불일치가 있으면 어느 값에서 얼마나 다른가
```

파일 값은 **그대로 읽는다.** 재계산·반올림하지 않는다.

## 판단하지 말 것

**수치만 보고한다.** 반올림이 원인인지, 무엇을 고쳐야 하는지 판단하지
않는다. 어긋남을 발견해도 코드나 문서를 고치지 않는다.

## 가장 중요한 제약 — 재구현하지 않는다

- 두 항 함수는 `src/engine/leagueStats.ts`에서 **import해 호출**한다
- `A`·`V`·`N`은 **`inferLoveType`에서 얻는다**
- `positiveBonus`는 `computeSixStats`가 쓰는 것과 **같은 판정**을 쓴다.
  그 판정이 export되지 않았다면 그 사실을 보고하고, 같은 문항 조건을
  쓴다는 것을 명시한다
- 반올림 함수와 자리수는 **코드에서 확인한 것**을 쓴다
- 파일 값은 **그대로 읽는다**

착수 전에 **재사용할 함수의 경로와 시그니처, 확인한 반올림 지점을
보고할 것.**
