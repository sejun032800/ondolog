## 2. 수정

| 경우 | 할 일 |
|---|---|
| 이미 사용자별 폴더 | 계정 전환 정리에 **이전 주인 폴더째 삭제** 추가(82- `queueOwner.ts` 정리 뒤 · 저장값이 깨져도 폴더 기준으로 지움) |
| 사용자별이 아님 | 새 파일은 사용자별 폴더에 저장 · **기존 파일 옮기기**(방식은 메인 세션 판단): 주인을 알 수 있는 파일만 옮기고, 옮긴 뒤 저장값의 경로를 갱신 · 주인을 모르는 파일은 **지금 세션 주인 것이 아님이 확실할 때만** 지움 — 확실하지 않으면 남기고 결정 기록에 |

- 같은 계정 재로그인 · 업데이트 덮어 설치 때 **보내지 못한 사진 0건 손실**(81- · 82- 규칙 유지)
