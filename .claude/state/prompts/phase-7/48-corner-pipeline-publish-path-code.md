**2. P0~P8 코드.**
- P3은 SCHEMA §9-D-3의 **조건부 UPDATE**를 쓴다

- 모델·캐시 설정은 **`coeffLookup.ts`를 거친다**
- 모델 값이 `tbd`면 생성을 멈춘다 (**fail closed**)

**3. 완료 기준.**
- **로컬 C 실증**: 정상 발행, 예외들, **같은 커플의 두 호를 동시에 발행하면 번호가 1·2로 나뉘는지**
- **테마 트리거 실증** (초안 theme ≠ 커플 값)
- **`supabase functions serve` 기동 확인**
- jest 게이트

**범위 밖.**
- **실제 LLM 호출.** 모델 값과 API 키가 사람 작업이라, 배치 송수신은 **가짜 전송으로** 시험한다
- **발행 Edge Function을 유저에게 여는 일** (Phase 8 뒤)
- MASTER §17-0-10-I의 사람 작업: 비밀값 등록, 모델 식별자 입력, pg_cron 등록, 배포, 실제 DB 쿼리 확인

**멈춤 조건은 하나다 — MASTER §17-0-10·SCHEMA §9-D에 없는 값이 필요할 때.** 그 부분에서 멈추고 필요한
값을 보고한다. 값을 지어내지 않는다. 그 밖에는 끝까지 진행한다.

다음은 **사람 작업이거나 허용 범위 밖이라** 고르지 말고 보고한다. 진행할 수 있는 나머지는 진행한다.
- import map 등 `functions serve`에 필요한 설정 파일이 없거나 바꿔야 할 때 (§17-0-10-I 사람 작업)
- DB 스키마 변경(새 마이그레이션)이 필요할 때 — 022는 적용됐고 §9-D가 원본이다

## 로컬 스택 — 안전 규칙

- 로컬 실증은 **`npx supabase start`로 띄운 로컬 스택에서만** 한다
- `db reset`은 **로컬에만** 쓴다. **`--linked`·`--db-url` 등 원격을 가리키는 옵션을 쓰지 않는다**
- `db push`, 원격 DB 접속·쓰기를 하지 않는다 (절대 규칙 6)
- CLI가 저장소의 추적 파일을 스스로 바꾸면(`supabase/.temp/cli-latest` 등) 되돌리고 보고한다
