## 4. PE 제안 — 최종 수정 뒤 확인 방식

1. 최종 수정 지시서의 폰 확인은 **`51-` 49항목을 한 번 끝까지 도는 것**으로 합니다(M0 §7 순서 · 멈춤 조건 4가지 그대로). 대기 목록의 폰 확인 항목은 그 단계 안에 끼워 넣습니다. 별도 탐방 3차를 두지 않습니다.
2. `51-` 문장 중 RN 고유 표현(U0 · B2 · B4)은 **웹판 문장으로 고쳐 쓰는 작업을 지시서에 포함**합니다. 원문은 남기고 `[웹: …]`를 붙이는 방식(r62 표기 규칙 그대로)을 권합니다.
3. ○ 19개 가운데 **준비물이 필요한 것**을 미리 적어 둡니다.
   - B3: HEIC로 찍은 사진
   - B9: 두 달에 걸친 기록
   - B21: 초기화하지 않은 기존 계정으로 앱을 재설치
   - C12: 메일 앱이 없는 상태(메일 앱 비활성화)
   - D7: 약한 신호 장소
   - 그 밖의 항목은 비행기 모드와 녹화만으로 됩니다.
4. 시드 시험 호(새 커플, 11월호 1권)는 남겨 두었다가 **B11 회귀**에 씁니다(R90-3). 다음 커플 모드 초기화 때 `--with-issues`로 정리합니다.

## 보완 의견 (PE)

- 탐방 2차의 가장 큰 수확은 **렌더 출시 차단 결함 2건(h5 · h5b)과 키 사고 정리**였습니다. 둘 다 계획한 확인 항목이 아니라 "실제 데이터를 한 번 끝까지 흘려 본 것"에서 나왔습니다. 최종 수정 뒤 `51-`을 돌 때도 **두 폰이 실제처럼 일주일치 기록을 만든 뒤 시드 호를 한 번 더 렌더**하는 단계를 끝에 두기를 권합니다(LLM 0 · 샘플 모드).
