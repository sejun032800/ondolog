## 1. 먼저 판정 (보고 맨 앞 · 손대기 전에)

**지금 코드에서 이전 사람의 대기열 · 보존 원본이 새 계정 세션으로 보내질 수 있는가?**

- 확인할 것: 대기열 항목이 보낼 때 누구로 보내는지(현재 세션 사용자 · 항목에 저장된 값) · 로그인 직후 큐 비우기가 언제 도는지 · `purgeOtherUsers`(`ondolog.dc1:` 키만) 범위 · 서버 권한(RLS)이 막는지 — **단, 판정은 서버 거부에 기대지 않고 앱이 보내려 하는지로**
- 판정: "경로 있음 / 없음" + 근거 + 재현 시험 이름
- **경로가 있으면 실제 커플 조건(R120-4)** — 보고 맨 앞에 크게. 고치는 것은 아래 2단계로 계속(멈추지 않음)

## 2. 수정 (R120-4)

| # | 규칙 |
|---|---|
| ① | 글 · 사진 대기열 · 81- 보존 원본 **항목마다 주인 계정 표시**. 표시가 없는 기존 항목은 **처음 읽을 때의 세션 주인**으로 붙임(81- 이전 값 받아들이기와 같은 원칙) — 세션이 없으면 표시 없이 보내지 않음으로 두고 다음 로그인 때 판정 |
| ② | 보낼 때 **항목 주인 ≠ 지금 세션 사용자면 절대 보내지 않음**(서버 거부에 기대지 않음) |
| ③ | **다른 계정이 로그인하는 순간** 이전 주인의 대기열 · 보존 원본 · 사진 대기열 파일 삭제(R118-2와 같은 원칙) · 지운 건수만 `PROGRESS`/로그에 숫자 0 — 오류 기록 대상 아님 |
| ④ | **같은 계정 재로그인은 이어서 보냄**(R39-5 b 유지) |
| ⑤ | 그 뒤 로그아웃 확인 문구에 R119-2 줄 추가: **"다른 계정으로 로그인하면 이 폰에서 사라져요."** — 대기열이 있을 때만, 확정 문구 순서는 R119-2 그대로 |

## 3. 채팅 탭 진입 때 서랍 지우기 (R120-2 · 작음)

- 채팅 탭(그 커플 채팅)에 들어가면 **그 커플의 메시지 알림만** 서랍에서 지움(변경 안내는 남김 · 다른 앱 알림 0). 플러그인 기존 기능(전달된 알림 목록 · 해당 태그만 지우기)으로 — 안 되면 "모두 지우기"로 대체하지 말고 멈추고 보고
