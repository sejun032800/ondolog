## 3. 디자인에 넘길 질문 — 360° 하늘이 텅 비어 보임

- **Proteur 판정**: 둘러볼 때 "텅 빈 하늘"처럼 느껴집니다. **은하수가 자연스럽게 쭉 이어져야** 합니다.
- **PE 측정**: 디자인 원본(`sky_pano_360.jpg`)을 30° 단위로 나눠 밝기를 재 봤습니다. 은하수는 0° 부근과 180° 부근 두 줄뿐이고, 나머지 약 **70%는 평균 밝기 8~9(0~255)인 거의 검은 하늘**입니다. 그래서 앱 문제가 아니라 원본 그림 쪽 문제입니다.
- **PE 제안**: 디자인 묶음 다음 차례(E1 · D3 쪽)에 "360° 원본 다시 그리기 — 은하수가 한 바퀴 내내 끊기지 않고 이어지게(밝기 · 띠 폭은 C01 그림과 같은 결), 이음매 0, 폭 3896px · 1.25배 규칙 그대로"를 질문으로 넣기. 앱 코드는 원본 파일만 바꾸면 되므로 반입은 작습니다(R151-3 압축 규칙).
- 실제 커플 시작을 막는 항목은 아니라고 봅니다(기능 정상 · 느낌 항목). PM이 시작 전 조건으로 올릴지 정해 주세요.

## 4. 2부 — 88-b 읽기 전용 로컬 렌더 (R152-3)

| 호 | 쪽(새로 / 발행) | 되받기 | 처음 그림 넘침 · 잘림 | 표지 |
|---|---|---|---|---|
| G 1호 | 14 / 14 | 0번 | 0 · 0 | `theme.headline` |
| 두 폰 11월호 | 9 / 9 | 0번 | 0 · 0 | `quote`(표제가 이 달의 말에서 옴) |

- **이미 발행된 두 호에는 넘침이 없었습니다.** v1.2.4로 다시 그려도 쪽 수가 같고 되받기도 0번입니다 → **R152-3 확인 끝**.
- Proteur가 PDF를 눈으로 본 결과: 문제 없음.
- **PE가 하나 더 확인 중**: 두 폰 11월호는 표제가 이 달의 말에서 왔는데 요약 값이 `coverQuoteRemoved: false`입니다.
  - v1.2.4 E3대로라면 표지 아래가 인용 줄 대신 "이 달의 말 · 이름" 한 줄이어야 합니다.
  - 이 값이 "렌더러가 따로 인용 줄을 지웠는가"(E3에서는 compose가 미리 비우므로 false가 정상)를 뜻하는지, 아니면 실제로 인용이 남았다는 뜻인지 PDF 표지로 확인하고 있습니다. Proteur에게 표지 한 줄을 물어 두었습니다.
- 끝내기 확인(창 닫기 · False 두 줄) 정상.
