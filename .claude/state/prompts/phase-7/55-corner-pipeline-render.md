R21-7. 사람이 `render/issue/`에 조판 소스를 넣고 커밋했다.

1. **상대 참조가 `render/issue/` 안에서 모두 풀리는가.** 템플릿 HTML·CSS의 폰트·이미지·CSS 참조를 전부 따라간다. **밖을 가리키거나 파일이 없는 참조가 하나라도 있으면 목록을 보고하고 멈춘다** — 사람이 빠진 파일을 가져온다
2. **폰트 파일 목록과 각 라이선스**(배포·임베드 허용 여부)를 적는다. 반입 소스 안에 라이선스 문서가 없으면 "확인 못 함"으로 적는다. 이 항목은 멈춤 조건이 아니다
3. 템플릿에 호 번호(Vol)·발행일 자리가 어디 있는지, 활자 표지(사진 없는 표지)가 있는지 적는다
