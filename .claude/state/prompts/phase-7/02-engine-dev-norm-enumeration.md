## 목표

응답 공간 3,888개를 전수 열거해 규준집단 데이터 파일 `norm-synthetic-v1.json`을
생성하고, 엔진에 백분위 조회 함수를 추가한다.

## 배경 (읽고 시작할 것)

6각 스탯은 에니어그램·애착·빅5를 자체 공식으로 결합한 **합성 지표**라 대응하는
공개 규준이 존재하지 않는다. 대신 응답 공간이 유한하다 — Q1~Q5 각 3지선다(3⁵=243)
× MBTI 16종 = 3,888개. 채점이 전부 결정론적 룩업·산술이므로 **전수 열거로 분포를
정확히 계산할 수 있다. 추정이 아니라 열거다.**

이 작업이 만드는 것은 이후 모든 유저의 스탯이 대조될 기준 분포다.

## 가장 중요한 제약 — 채점 로직을 재구현하지 않는다

**Phase 2에서 만들어진 기존 채점·스탯 함수를 그대로 import해서 열거한다.**

열거용으로 채점을 다시 구현하면, 규준집단이 실제 유저 채점과 **다른 분포**가 된다.
유저는 함수 A로 채점되는데 백분위는 함수 B의 분포에 대고 매겨지는 상태가 되며,
양쪽 다 결정론적이라 테스트는 전부 통과한다. **런타임에 아무 에러도 나지 않고
값만 조용히 틀린다.**

작업 시작 전에 아래를 먼저 하라.

1. `src/engine/` 하위에서 5문항 채점(에니어그램 코어·빅5·애착·스턴버그)과
   6각 스탯 산출을 담당하는 기존 함수를 찾는다
2. **찾은 함수의 경로와 시그니처를 보고한다**
3. 그 함수들만 사용해 열거한다

기존 함수가 없거나, 있어도 문서(Part 10-2 / 17-3)와 어긋나 보이면
**멈추고 보고할 것.** 임의로 새로 짜지 말 것.

## 규준 데이터에 반드시 포함할 것

```
version: "synthetic-v1"
```

**① 스탯별 분포** (PUS · EMP · ATT · DEF · TAC · REA 각각)

- 평균, 표준편차, 분위수
- 백분위 조회가 가능한 형태 (정렬 배열 또는 백분위 격자 — 형태는 판단에 맡긴다)

평균은 베이지안 수축의 사전평균으로 쓰이고, **표준편차는 수축 강도를 정하는
근거가 된다.** 이 열거가 그 관측을 만드는 유일한 작업이므로, 빠뜨리면 나중에
전부 다시 돌려야 한다(Part 10-8-1).

**② 합성값 분포** — 6각 스탯의 산술평균(프로파일당 1개, 3,888개)의 분포

스탯별 분포와 **동일한 형식**으로 함께 산출한다.

> **왜 둘 다인가.** OVR 산출에서 산술평균이 백분위 변환 앞인지 뒤인지가
> Part 10-8-2에서 두 갈래로 읽힌다. 마스터 PM 확정 대기 중이며, 양쪽 데이터를
> 지금 다 만들어두면 어느 쪽으로 정해지든 재열거가 필요 없다.
> **이 작업에서 그 순서를 판단하거나 결정하지 말 것.**

## 원점수 기준으로 열거한다

**수축(shrinkage)을 적용하지 않은 원점수로 분포를 만든다.**

수축의 사전평균이 이 분포에서 나오므로, 열거 단계에서 수축을 적용하면
자기 자신을 입력으로 요구하는 순환이 된다. `leagueStats.shrinkage`는
`UNRESOLVED` 상태 그대로 두고 이 작업에서 건드리지 않는다.

각 응답 조합은 **균등 가중**한다(Part 10-8-1).

## 검증 조건 — 에니어그램 코어 9종별 분포

Part 10-8-2가 완료 기준으로 지정한 항목이다.

6각 스탯이 유형에서 도출되므로 특정 에니어그램 코어가 구조적으로 낮은 값을
받을 수 있고, 백분위 변환은 순위만 보므로 이를 교정하지 못한다.

**코어 1~9 각각에 대해 합성값의 평균·표준편차·최소·최대를 산출해 보고한다.**
특정 코어가 체계적으로 하위 구간에 몰리는지 사람이 판단할 수 있는 형태여야 한다.

**판단은 하지 말 것.** 수치만 보고한다. 가중치 도입 여부는 마스터 PM 결정이다.

## 완료 기준

- 데이터 행 수가 정확히 **3,888**이다
- **재실행 시 바이트 단위로 동일한 파일이 생성된다** (결정론 검증)
- 기존 채점·스탯 함수를 재사용했으며, 열거용 채점 재구현이 없다
- 스탯 6종 각각의 평균·표준편차·분위수가 포함된다
- 합성값 분포가 동일 형식으로 포함된다
- 백분위 조회 함수가 **순수 함수**이며 결정론 테스트를 통과한다
- 에니어그램 코어 9종별 합성값 분포가 보고서에 포함된다
- 기존 테스트 267개 전부 통과
- `npx tsc --noEmit -p .` 통과 (**0 에러**)
- `grep -rn "UNRESOLVED" src/engine/`가 여전히 3건 — 이 작업으로 늘거나 줄지 않는다
