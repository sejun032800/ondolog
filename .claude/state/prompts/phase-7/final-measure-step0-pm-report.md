## 3. 메인 세션이 바로잡은 것 — 받을 만함

- 커플 · 호 id는 사람이 치지 않고 변수로만 받습니다.
- `--mode live` 앞에 **`migration list`(읽기만)**를 넣었습니다. 84-a의 LLM 설정 마이그레이션이 원격에 들어갔는지 기록이 없기 때문입니다.
