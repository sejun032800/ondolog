## 1. 할 일

연결된 시험 커플(폰 A · 폰 B)에 **시드 시험 호 1권**을 **기존 운영자 경로**(시드 → 렌더 → 발행 스크립트, R53-6)로 개발 프로젝트에 발행합니다.

1. 먼저 쓸 스크립트와 순서를 저장소에서 찾아 **명령 목록**을 확인합니다. 새 스크립트를 만들거나 기존 스크립트를 고치지 않습니다.
2. **대상 커플**: 개발 프로젝트에 연결된(활성) 커플이 **지금 하나뿐이면** 그 커플입니다. **둘 이상이거나 0이면 멈추고 보고**합니다. 이메일 · id를 파일이나 보고에 적지 않습니다.
3. 렌더 산출물은 매거진(화면용) PDF와 인쇄용 PDF가 따로 있다면 **경로 · 버킷 규칙을 기존과 같게** 둡니다. 인쇄용 PDF가 앱 사용자에게 열리는 경로로 올라가면 안 됩니다(절대 규칙 3) — 확인만 하고 보고합니다.

## 2. 멈추는 조건

- 실행에 **서비스 키가 필요한데 메인 세션 터미널에 이미 있지 않으면**, 키를 요청하지 말고 **Proteur가 직접 칠 한 줄 명령**을 단계별로 줍니다(HANDOFF의 `Read-Host -AsSecureString` 방식, 값이 화면에 찍히지 않게). 키 · 주소 · ref를 보고나 파일에 적지 않습니다.
- 경로가 코드 수정 · 마이그레이션 · 새 패키지를 요구하면 멈추고 무엇이 필요한지만 보고합니다.
- 대상 커플이 하나로 정해지지 않으면 멈춥니다.

## 3. 보고 (짧게)

1. "Proteur 지시로 메인 세션 실행" 또는 "Proteur가 직접 실행할 명령"
2. 실행한 단계(시드 · 렌더 · 발행) 각각 성공 / 실패
3. **"발행됨 · 매거진 파일 수 N · 인쇄용 PDF 앱 노출 경로 0(확인 방법 한 줄)"** — 호 ID · 커플 ID · 주소 0
