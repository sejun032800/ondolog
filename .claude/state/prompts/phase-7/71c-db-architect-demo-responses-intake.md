## 전제 (절대 — R56-5)

**`demo_responses`의 데이터는 어떤 일이 있어도 지우거나 바꾸지 않는다.** 이 테이블은 실제 사용자의 웹 체험판 응답이다.

- 원격에 쓰지 않는다. `migration repair` · `db reset` · `db push`를 쓰지 않는다
- **`supabase/migrations/` 안에 고의 실패용 파일이나 임시 파일을 만들지 않는다.** 고의 실패는 시험 안의 임시 폴더에서만 한다(§C-④). 저장소의 마이그레이션 폴더에 들어간 파일은 사람이 `db push`로 원격에 올릴 수 있기 때문이다
- 편입 파일 본문은 원격 기록 그대로 둔다. 고치지 않는다

| # | 할 일 |
