## PM 요구 — 설계가 답해야 할 것

1. **기간 내 채팅·사진·데이트 조회, 17-1의 재소환**
2. **`occurredAt`·`recalled`·`kind`·`source`를 싣는다** — 코드의 타입 정의대로
3. **표기의 날짜·시각 부분** — 시간대 라벨은 `timeOfDayLabel` 함수를 쓴다
4. **다른 커플의 레코드가 섞이지 않는다는 것을 조회 단계에서도 보장한다.** 골격의
   호출 전 단언은 **마지막 방어선**이지, 조회가 아무렇게나 해도 된다는 뜻이 아니다

## 보고할 것

각 요구에 대해 **무엇을 어디에 어떤 형태로** 둘지와 **무엇으로 증명할지**를 적는다.
특히:

- 모듈 위치와 DB 접근 방식(어떤 권한으로 조회하는지, RLS와의 관계)
- 4번을 **조회 단계에서 어떻게 보장하는지**, 그리고 그것을 시험하는 방법
- 테스트를 실제 DB 없이 할지, 할 수 있다면 어떻게 할지
- 문서에 값이 없어 정해야 하는 것 — **지어내지 말고 질문으로** 적는다
