## 목표

DEF 애착 항 두 종의 전수 평균을 산출하고, 규준집단 파일에서 DEF 평균을
**직접 재추출**한다. 숫자 몇 개만 내면 되는 작업이다.

## 이 작업은 아무것도 바꾸지 않는다

**`src/` 아래 어떤 파일도 만들거나 고치지 않는다.**
공식도, 규준집단 파일도 건드리지 않는다. 조회 전용 스크립트 하나와
그 출력이 전부다.

## 배경 (읽고 시작할 것)

DEF의 애착 항이 두 번 바뀌었다.

```
v2 : computeAttachmentStability(A, V) = 100 − (A + V) / 2
v3 : computeDefAnxietyStability(A)    = 75 − A / 2
```

DEF의 나머지 항(정서안정성, 긍정형 보너스)은 두 판에서 동일하므로,
DEF 평균의 변화는 **오직 이 항의 평균 차이 × 0.3**이어야 한다.

그런데 규준집단 파일에서 읽은 DEF 평균의 변화가 그 값과 어긋난다.
**이 진단은 어긋남이 항에 있는지, 아니면 저장된 수치 자체에 있는지를
가른다.**

## 가장 중요한 제약 — 항을 재구현하지 않는다

**두 항 함수를 `src/engine/leagueStats.ts`에서 그대로 import해 호출한다.**

식을 다시 적으면 문서 정의대로 계산하게 되고, **이 진단이 찾으려는
바로 그 차이가 사라진다.** 구현된 것이 문서와 같은지를 보는 작업이므로,
구현을 그대로 불러야 한다.

`computeAttachmentStability`는 본문 무변경으로 남아 있고 EMP가 계속 쓰고
있다. `computeDefAnxietyStability`는 나중에 신설됐다. **둘 다 현재 코드에
존재한다.**

착수 전에 **두 함수의 경로와 시그니처를 보고할 것.** 없거나 이름이 다르면
멈추고 보고한다.

## 산출할 것 — 넷

### ① 두 항의 전수 평균

3,888 프로파일 각각에 대해 `attachAnxiety`·`attachAvoidance`를
**기존 채점 함수(`inferLoveType`)로 얻고**, 두 항 함수에 넣어 평균을 낸다.

```
termV2mean = E[computeAttachmentStability(attachAnxiety, attachAvoidance)]
termV3mean = E[computeDefAnxietyStability(attachAnxiety)]
termDiff   = termV3mean − termV2mean        ← 부호와 순서를 이대로 지킬 것
```

**`termDiff`는 반드시 `v3항 − v2항`이다.** 반대로 계산하면 아래 ④의
역산이 부호가 뒤집혀 결론이 반대로 나온다.

소수점 **12자리 이상**으로 보고한다.

### ② 규준집단 파일의 DEF 평균 재추출

`norm-synthetic-v1.json` · `v2.json` · `v3.json` 세 파일에서 **DEF 분포의
평균을 직접 읽어** 파일에 저장된 값 그대로 보고한다.

**반올림하거나 다시 계산하지 말 것.** 파일에 있는 값을 그대로 옮긴다.

> **v1과 v2의 DEF 평균은 같아야 한다.** 그 사이 변경은 EMP 공식뿐이고
> DEF는 건드리지 않았다. 다르면 그것도 보고 대상이다.

### ③ 현재 코드로 계산한 DEF 평균

3,888 프로파일에 대해 **현재 `computeSixStats`가 내는 DEF의 평균**을
산출한다.

### ④ 대조 넷

아래 네 값을 나란히 보고한다. 전부 위에서 이미 구한 수의 산술이다.

```
(a) ②v3 − ②v2                파일 기준 DEF 평균 변화
(b) 0.3 × termDiff            항 변화가 예측하는 DEF 평균 변화
(c) ③ − ②v3                  현재 코드와 v3 파일의 일치 여부
(d) (③ − 0.3 × termDiff) − ②v2
```

`(d)`는 **현재 코드에서 v2 시절 DEF 평균을 역산해 파일값과 비교**하는 것이다.
v2 시절 코드는 남아 있지 않으므로 직접 재계산할 수 없고, 두 판의 DEF가
항만 다르다는 성질을 이용한다.

## 판단하지 말 것

어디를 고쳐야 하는지 판단하지 않는다.

**어긋남을 발견해도 코드나 문서를 고치지 말 것.** 그 발견이 산출물이다.
