## 할 일

### ① 다정한 말 자기 점검 (R137-3)

- 다정한 말 코너가 **같은 호출 안에서** 고른 각 줄(대화 · 한 줄 선택)마다 **"다툼 · 화해 맥락인지" 표시**를 함께 내게 합니다(응답 형식에 칸 추가). 출처: MASTER 17-4 · §17-0-9-F-2(r61) — 낱말 규칙이 아니라 LLM 판단
- 엔진은 **표시된 줄을 뺍니다.** 빼고 남은 줄이 코너 최소 분량보다 적으면 지금의 "모자라면" 규칙을 따릅니다(파일:줄)
- **표시가 빠진 줄 = 형식 오류**(지금 재요청 규칙 → 빠짐)
- 추가 호출 0 · 프롬프트 · 응답 형식 · 예문 · 시험(표시 있음 → 빠짐 · 표시 없음 → 형식 오류 · 모두 표시 → 모자람 처리)
- **`recheck`**: 저장된 2차 결과에는 이 칸이 없습니다. 2차 결과가 "표시 없음 = 형식 오류"로 어떻게 걸리는지 **보고만** 하고, recheck가 이 칸이 없는 옛 결과를 어떻게 다룰지(건너뜀 · 표시) 정해 결정 기록에 적습니다
