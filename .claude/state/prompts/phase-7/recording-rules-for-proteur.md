# Proteur 상시 — 폰 녹화 규칙 (R118-6 · 앞으로 모든 녹화)

> 개인정보가 찍힌 것이 다섯 번 — 규칙을 늘리는 대신 **그 화면을 지나지 않는다**

## 녹화 전
1. **두 폰 모두 방해 금지 켜기**(예외 앱 = 온도록만)
2. **서랍을 열기 전에** 다른 앱 알림을 모두 지우기(서랍 아래 "모두 지우기")
3. 두 폰 **동시에** 녹화 시작 · 시작할 때 상태 표시줄 날짜 1초

## 녹화 중
4. **폰 "설정" 앱 첫 화면에 들어가지 않기**(이름이 나옴) — 온도록 알림 설정 등은 **앱 아이콘을 길게 누름 → 앱 정보**로 바로
5. 카카오 계정 화면 · 메일 · 연락처 · 공유 시트가 나오면 **녹화 일시정지**

## 녹화 뒤
6. PE 판독이 끝나면 **두 파일 삭제**(저장소에 넣지 않음)
