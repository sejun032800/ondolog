## 왜

처리방침(`consent.ts` v1.1)은 세 가지를 약속합니다.

1. "내가 올린 사진 · 메모는 언제든 지울 수 있습니다"
2. "탈퇴하면 7일 뒤 지웁니다"
3. "해제하면 7일 뒤 요청한 사람의 기록을 지웁니다"

실제 동작은 다릅니다.

- 사진 · 하루를 지우면 행만 지워지고 **저장소 파일은 남음**
- **탈퇴 7일 뒤 최종 삭제가 없음**
- 해제 실행도 파일이 남는 것으로 보임

**문안을 약하게 고치지 않고 구현을 문안에 맞춥니다**(PM 결정). 문안 · `consent.ts`는 **편집 0**.

  - 하루 지우기 RPC는 지운 행의 파일 경로를 돌려주는 것이 필요할 수 있음 → **마이그레이션이 필요하면 (a)의 하루 지우기 부분만 멈춤**. 이때 (b)가 정리한다는 점을 보고에 적음

- 상대 파일은 지우지 않음(저장소 권한이 막는지 확인 · 보고)
