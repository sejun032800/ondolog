## 허가 · 금지

- **읽기만**: 저장소 파일 읽기 · 정적 검색 · 기존 시험 목록 보기
- **0**: 코드 · 문서 · 설정 변경(HANDOFF · PROGRESS에 "84-0 조사 완료" 한 줄만 허용) · 커밋 · **LLM 호출(실제 · 모의 실행 모두)** · 렌더 실행 · 원격 접속(R112-3 — 이번 허용 질의 없음) · `demo_responses` 읽기 · 건수
- 보고에 키 · 주소 · ref · id · 이메일 · **프롬프트 전문** 0(프롬프트는 위치와 길이 · 구조만)
- 모든 서술에 근거(파일:줄 또는 시험 이름). 근거가 없으면 "확인 필요"(R119-5)

## 조사 항목

### 1. 코너별 표

| 코너 | 쓰는 방식(LLM / 결정적 계산 / 템플릿 / 사진만) | 입력 데이터 | 프롬프트 위치(파일:줄) · 대략 길이 | 출력 검증(스키마 · 길이 · 금지어) | 실패 때 대체 | 시험 |
|---|---|---|---|---|---|---|

- 표지 · 목차 · 기념일 · featured · 대화 하이라이트 · 성격(Big5/DNA) · 온도 · 장소 · 편집자 노트 등 실제 렌더에 있는 코너 **전부**

### 2. 모델 · 설정

- 모델 이름을 정하는 곳(`app_config` 등 · 파일:줄) · 기본값 · **fail-closed 동작**(설정이 없거나 잘못되면 어떻게 멈추는지)
- 온도(temperature) · 최대 토큰 · 재시도 · 시간 제한 · 동시 실행
- 키를 읽는 곳(이름만 · 값 0)

### 3. 품질 하네스 `m1QualityRun.ts`

- 무엇을 재는지(지표 · 판정 기준) · 시드 데이터(어디 · 몇 커플 · 실제 사람 데이터 0인지)
- 지금 돌릴 수 있는 상태인지(빠진 것) · 마지막으로 돈 기록(PROGRESS · HANDOFF 근거)
- 출력이 어디에 남는지(저장소 밖인지)

### 4. 쌓인 M1c 판정 항목 — 현재 상태

| 항목 | 원래 뜻(ROADMAP 근거 줄) | 지금 코드 상태 | 남은 일 |
|---|---|---|---|

- R19-2 featured 대체 · R29-5 · R44-9 Evidence.path · R50-8 · R51-4 · R52-3

### 5. 비용 · 시간 추정 (계산만 · 실행 0)

- 1호(한 커플 한 달) 렌더에서 LLM 호출 수 · 호출당 입력 · 출력 토큰 추정(시드 데이터 기준 · 근거: 프롬프트 길이 + 데이터 크기)
- 하네스 1회(전체 시드) 호출 수 · 토큰 합 · 걸리는 시간 추정
- 가격표는 넣지 않음(PE가 공식 가격으로 계산) — 모델 이름과 토큰 수만

### 6. 렌더 쪽 연결

- 샘플 모드 / 실제 모드를 가르는 곳 · 실제 모드로 바꿀 때 필요한 것 목록
- 렌더 결과 PDF 크기(R74-h5b 2.12MB 기준과 비교)
