## 할 일 — 다섯 가지

### 1. 다정한 말들 프롬프트 문구 복원 (A)

`sweetWords.ts`의 "다툼에 덮인 것"을 **MASTER 17-4 문구 "덮인 것을 다시 꺼내주는 것"**으로 되돌린다.
`52-`에서 들어간 "다툼에"를 빼는 일이다. 같은 프롬프트의 다른 문장은 바꾸지 않는다.

### 2. 입력 전처리 — sel-a만 운영 경로에 연결 (B, 17-0-9-F-2)

- **`52-`의 sel-a(의미 없는 조각 제거)만** 운영 경로에 넣는다
- 하네스(`scripts/ops/`)의 **cap-\*·sel-b~d 옵션은 dry 전용으로 그대로 둔다**. 운영 경로에 넣지 않는다
- **운영 경로는 `scripts/ops/`를 import하지 않는다** (`supabase/functions` 쪽 tsconfig가 따로 본다)
- 17-0-9-F: **뺀 것은 세어서 반환한다** — sel-a로 뺀 건수도 사유별 제외 건수에 들어가야 한다. 기존 사유("본문 없는 메시지")와 겹치는 부분을 어떻게 셀지는 내부 결정이다

### 3. 안전 정지 — 코너별 추정 입력 토큰 > 40,000 (B, 17-0-9-F-2)

- 코너 하나의 **추정 입력 토큰이 40,000을 넘으면**(초과. 40,000 자체는 생성한다) **LLM을 부르지 않고**, 그 사유(코너, 추정값, 상한)를 남긴다
- **추정은 sel-a를 거친 뒤, 실제로 보낼 입력 전체**(system·user 블록)를 대상으로 한다
- **추정 방법은 `52-`에서 보고한 방법**(`TOKEN_WEIGHTS`, 글자 종류별 가중치)을 쓴다. 공급자 토크나이저·토큰 세기 API는 쓰지 않는다(실제 호출 금지)
- **사유 값의 제약.** 실패 사유는 17-0-5에서 **Zod 스키마에 포함된 4값**이고, 이번 금지에 **출력 스키마 변경**이 있다. 그러므로
  - **다섯째 값을 만들지 않는다**
  - **4값 중 하나로 기록하지도 않는다** — 어느 값으로 볼지는 제품 사실이고 아직 정해지지 않았다(예: `insufficient_input`의 유저 문구는 "이번 달 기록이 적어서"다)
  - 4값 밖의 **생성 전 정지 결과**로 남긴다. 17-0-4-B(소속 단언)의 "그 코너: 실패 사유를 기록하지 않는다"와 같은 층이다. 그 결과의 모양(오류·반환 변형 등)과 위치는 내부 결정이다
  - 위가 4값 유니온·Zod 스키마를 건드리지 않고는 안 되면 **멈추고 그 지점을 보고한다**
- `ops_alerts` 쓰기는 발행 경로의 일이다. 이번에 넣지 않는다
- **하네스 `run`도 이 정지를 거쳐야 한다** — M1c에서 정지가 실제로 보이게

### 4. 데이트 단위 메모·사진을 17-1 user 블록에 (E, 17-0-9-F-2)

- **`DateSource.dateLevel`의 메모·사진을 17-1 프롬프트 user 블록에 읽기 전용 맥락으로 싣는다**
- **출력 스키마는 바꾸지 않는다.** 지면에 인용하는 방식은 M1c 뒤에 정한다(17-0-9-F-2)
- **ID 참조 선언을 바꾸지 않는다.** dateLevel 사진이 지금 참조 가능 목록에 없으면 더하지 않는다. 있으면 그대로 둔다. 어느 쪽인지 보고한다
- system 블록에 이 맥락을 어떻게 다루라고 쓸지는 17-0-9-F-2 문장 범위 안에서 정한다

### 5. 재소환 데이트의 featured 자격 (F, 17-0-7 표)

**이번 달 데이트가 1건 이상이면 재소환 데이트는 대표 화보(featured)가 될 수 없다. 0건일 때만 재소환에서 고른다.**

- **결정론 규칙이므로 LLM 지시가 아니라 코드(파생 또는 검증 단계)에서 강제하는 쪽을 우선한다** (PM)
- 제약
  - 출력 스키마·ID 참조 선언을 바꾸지 않는다
  - **ROADMAP M1b의 경계** — 기존 검증 순서를 바꾸거나 새 검증층을 끼우지 않는다
  - 코드가 LLM의 선택을 **다른 데이트로 바꿔 끼우는** 방식이면, 무엇으로 바꿀지는 제품 사실이다. 정하지 않는다
- 위 제약 안에서 코드로 강제할 수 없으면 **프롬프트 지시로 넣고**, 코드로 못 한 이유와 가능한 방법을 보고한다
- 17-1 프롬프트의 featured 선별 순서 문구가 이 규칙과 어긋나면 맞춘다
- **기존 시험 기댓값이 바뀌면 파일·줄·이전 → 이후를 전부 보고한다**
