## 2. `81-b` 멈춤 — 로그아웃 경고 문구 (PE 오류)

- 메인 세션 확인 사실: **로그아웃은 글 · 사진 대기열을 지우지 않음**(R39-5 b · `settingsFlow` 시험이 단언). 같은 계정으로 다시 로그인하면 이어서 보냄. 로그아웃 때 지워지는 것은 **81- 보존 원본(변환 못 한 것)뿐**
- **PE 81- 보고 §A-4의 "로그아웃 때 대기열을 지우는 기존 규칙(76-)"은 사실과 다릅니다.** PE가 근거 없이 적었고, R118-2 · R118-3 문구가 그 위에서 정해졌습니다. 정정합니다
- Proteur가 PE에게 결정을 맡김 → **PE 처리(PM 문구 의도 유지, 사실에 맞춤)**:
  - 동작은 **그대로**(R39-5 b — 같은 사람의 글을 잃지 않음이 R118-2 원칙과 같음)
  - 문구를 사실대로:
    - 대기열만 있을 때: **"아직 보내지 못한 메시지 {n}개가 있어요. 같은 계정으로 다시 로그인하면 이어서 보내요."**
    - 다른 계정 로그인 때 대기열이 지워진다면 한 줄 더: **"다른 계정으로 로그인하면 이 폰에서 사라져요."**(메인 세션이 계정 전환 삭제 동작을 확인한 경우만)
    - 보존 원본이 있을 때: **"보내지 못한 메시지 {m}개는 로그아웃하면 이 폰에서 사라져요."**
  - R118-3의 뜻("말없이 지우지 않는다")은 그대로 지켜집니다. **문구 확정은 PM**이 다시 정하면 그것으로 바꿉니다
