### 관찰 — 같은 알림을 "조용히 갈아 끼움" (PM 결정 필요)

- A가 홈에 있던 0:49~1:01에 B가 날짜를 **두 번 더** 바꿨으나(B 0:51 · 0:57), A 화면 위쪽에 **알림 팝업이 0프레임**(0.25초 간격으로 확인). 이때 서랍에는 0:42의 온도록 알림이 **읽지 않은 채 남아 있었음**
- 해석: R109-2에 따라 같은 태그 알림을 **갈아 끼울 때, 이 기기(삼성)에서는 소리 · 팝업 없이 내용만 바뀜**. 78- 2차의 "5건 연달아 → 서랍에 하나"와 같은 동작이고 설계대로입니다
- 문제가 되는 경우: **읽지 않은 알림이 서랍에 남아 있으면, 몇 시간 뒤 온 새 메시지도 울리지 않을 수 있음**(예: 오전 알림을 안 보고 두었는데 저녁 메시지가 조용히 갈아 끼워짐)
- PE 제안: "같은 태그라도 **직전 알림 뒤 N분(예: 10분)이 지나면 다시 울림**"(연타는 하나로, 긴 공백 뒤에는 다시 알림). 함수 쪽 작은 변경(태그에 시간 구간을 넣거나 다시 울림 표시)으로 될 가능성이 큼 → **PM이 원하면 `81-b`**
- 확인 방법(다음 녹화): A 서랍에 읽지 않은 온도록 알림을 둔 채 2~3분 기다렸다가 B가 메시지 → 팝업 · 소리가 나는지
