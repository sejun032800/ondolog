## 0. 준비 — 실행 명령을 메인 세션이 적게 하기 (키 · 비용 없음)

        4) 시험 커플 실제 모드 1호 생성(--mode live · 시험 커플 보호 장치 · Sonnet 5.5 · 기간 2025-09) → 발행 → v1.2.3 렌더 → PDF가 생기는 위치
        5) 각 명령이 원격에 쓰는 것(표 · 행 종류)을 한 줄씩, 비용 상한($2/호 · $10/명령)이 어디서 걸리는지

        7) 키 · URL · id · 이메일은 명령에도 출력에도 0. 명령이 원격에 쓰는 것은 시험 커플 행뿐인지 확인한 근거(파일:줄)

## 1. 키 넣기

1. console.anthropic.com → API Keys → **Create Key**(이름 예 `ondolog_final_2026_11`) — 복사 버튼으로만
2. **시작 메뉴**에서 PowerShell → 맨 위 폴더
3. HANDOFF "최종 실측 실행 명령" 1)의 줄을 그대로 → **True**일 때만 계속

## 3. 시험 커플 1호 (실제 모드)

- HANDOFF 3) → 4)를 순서대로 — 순서는 **생성 → 렌더 → 발행**입니다(렌더는 이미 발행된 호를 거부함 · 메인 세션 정정)
- 모든 명령은 HANDOFF의 **출력 가리개 함수 `m`**을 거쳐 칩니다(호 id · 커플 id · 이메일이 `<id>` · `<email>`로 보임). 커플 · 호 id는 직접 치지 않고 변수(`$cid` · `$iid`)로만
- `--mode live` 앞의 `npx supabase migration list`(읽기만)에서 LLM 설정 마이그레이션이 원격에 없으면 멈추고 PE에게
- 끝에 나온 **PDF**를 엽니다(5번 판정에 씀)
- 시험 커플 화면 · PDF에 **"2025년 9월"**로 보이는 것은 정상입니다(R134-6)
