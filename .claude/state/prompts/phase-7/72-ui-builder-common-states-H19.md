### 1-1. H19 앱 정보 · 문의

- **보드대로** 만든다. H01 설정 목록에서 H19 항목을 다시 보이게 한다.
- **버전**: 앱 버전 값을 그대로 보여 준다. 값을 읽는 방법은 이미 저장소에 있는 것으로 하고, 무엇을 썼는지 보고한다. **"최신" 표시는 뺀다**(업데이트 확인 기능이 없다).
- **문의하기**: 메일 앱을 연다. 새 의존성 없이 `mailto:`로 연다.
  - 받는 주소는 **상수 하나**(`SUPPORT_EMAIL`)에 둔다. 값은 `TODO_SUPPORT_EMAIL` 자리표시자로 둔다. Proteur가 운영용 주소를 넣는다. **개인 주소를 코드 · 문서 · 시험 어디에도 넣지 않는다.**
  - 제목: `[온도록 문의]`
  - 본문 머리: 앱 버전 · OS(+ OS 버전) 두 줄과 "발행물 정정 요청이면 몇 월호 몇 쪽인지 적어 주세요" 한 줄
  - **계정 id · 이메일 · 이름 · 커플 정보는 자동으로 넣지 않는다**
  - 메일 앱을 열 수 없을 때의 처리는 보드대로(보드에 없으면 I06 토스트로 주소를 안내 — 보고)
- **이용약관 · 개인정보 처리방침**: 온보딩 동의에서 쓰는 같은 화면 · 문서를 재사용한다. 새로 쓰지 않는다.
- **오픈소스 라이선스**: 숨긴다(M4-9).
