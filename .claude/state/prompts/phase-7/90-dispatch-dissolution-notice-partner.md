### ② 고치기 — 규칙

| 항목 | 규칙 |
|---|---|
| 언제 | 기존 두 때(탭 처음 열림 · 다시 보임)에 **더해**, 앱이 켜져 있는 동안 커플 상태가 `dissolving`으로 **바뀌는 순간**(실시간 · 새로 읽기 어느 쪽이든) |
| 누구에게 | **상대가 개시한** 해제일 때 받은 쪽에만. 개시자 쪽은 0(지금 규칙 그대로) |
| 몇 번 | **해제 id당 한 번**(지금 규칙 그대로 — 앱을 켠 동안 한 번. 다시 켜면 아직 진행 중인 해제는 다시 한 번). 여러 때가 겹쳐도(실시간 + 다시 보임 동시) 한 번만 |
| 어디서 | 지금처럼 **탭 화면에서만**. 온보딩 · 로그인 · 다른 전체 화면 흐름 중이면 탭으로 돌아온 첫 순간에 한 번 |
| **입력 보호** | 받은 쪽이 **글을 쓰는 중**이면 그 입력을 잃지 않아야 합니다. 예: 채팅 입력칸에 친 글 · 기록 시트 · 데이트 기록 중. H14가 위에 쌓이고, 뒤로 가면 입력이 그대로 남아 있어야 합니다. 쓰던 시트가 닫히거나 입력이 지워지면 안 됩니다. 지금 쌓는 방식(urgent 푸시 · 뒤로 가기로 하나씩)이 이것을 지키는지 시험으로 확인합니다 |
| 취소되면 | H14가 떠 있는 동안 개시자가 **취소**해서 커플이 `active`로 돌아오면, 받은 쪽 H14가 **유예 상태를 계속 보여 주지 않아야** 합니다(옛 화면이 남지 않게). 닫히든 "연결 상태"로 바뀌든 지금 설정 화면 규칙을 따르고, 어느 쪽인지 보고합니다 |
| 기기 저장 | 새 기기 저장값을 만들면 R117-2(모양 버전 · 읽을 때 검사 · 범주 · 로그아웃 때 지움)를 따릅니다. 메모리만으로 되면 저장값 0이 좋습니다 |
