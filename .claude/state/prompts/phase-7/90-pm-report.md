## 4. PE 의견

1. **부수 효과 — 채팅 글이 탭을 옮겨 다녀와도 남습니다.** 메모리에만 있고 계정 · 커플이 바뀌면 버려지므로, 사생활 문제 없이 오히려 좋아진 동작으로 봅니다. 받기를 권합니다.
2. **남은 빈틈 — 받은 쪽이 화면을 켜 둔 채 아무것도 안 하면** 다음 다시 읽기(탭 바꾸기 · 잠금 풀기 · 재연결)까지 모릅니다.
   - 실제로는 폰을 잠갔다 풀거나 탭을 바꾸는 순간 바로 뜨므로, 7일 유예 앞에서 놓칠 가능성은 매우 낮습니다.
   - 완전히 막으려면 (가) `couples` 실시간 발행(서버 · 마이그레이션) 또는 (나) M4 해제 푸시가 필요합니다. PE는 **(나)와 함께 M4에서**를 권합니다. 따로 일을 늘리지 않습니다.
   - 앱 안에서 몇 분마다 다시 읽는 방법도 있지만, 배터리 · 요청 수가 늘고 R153-4 동결과도 맞지 않아 권하지 않습니다.
3. **스모크 전용 열림(`smoke/entry.tsx`)**: 운영 번들에 들어가지 않는지가 중요합니다. 지금 gate의 운영 번들 검사(84-h 시험판 미리 보기 검사와 같은 자리)가 이것도 보는지 다음 위임 때 한 줄 확인을 붙이겠습니다. 스모크 빌드는 별도 진입점이라 위험은 낮습니다.
