## 4. 새로 찾은 것 2가지

1. **시험 데이터 달력이 1년 어긋납니다.** 날짜는 2026년으로 적혀 있지만, 요일이 들어간 메시지 22건은 모두 **2025년 달력**과 맞습니다. 2026-09-01은 화요일인데 메시지는 "월요일"이라고 합니다. "이번 주만 지나면 추석"도 2025년 기준입니다(2026년 추석은 9/25).
   - 그래서 지면의 요일 언급 13곳은 메시지와는 맞지만, 2026년 날짜로 따지면 모두 하루씩 어긋납니다.
   - 모델 잘못이 아니라 데이터 문제입니다. 하지만 실제 사용자 데이터에서도 모델이 요일을 **메시지 문맥으로 추론**하고 있다는 뜻입니다. 입력 레코드에는 요일 칸이 없습니다.
2. **"근거" 칸 18개가 모두 "~있어서"로 끝나 문장이 닫히지 않습니다.** 맞춤 질문은 회차마다 해요체("~볼까요?")와 반말("~볼까?", "의향은?")이 섞입니다. R125-1(매거진은 합니다체)이 이 짧은 칸들까지 덮는지 정해져 있지 않습니다.
