### 고지 문구 (PM 결정 — R31-9)

디자인 D10 보드의 "수록된 사진과 문장은 두 사람이 남긴 기록이며, 편집 외의 각색은 하지 않았습니다"는 **사실과 다르다** — 호 안에는 온도록이 쓴 문장이 있다(발행 노트가 비율을 공개한다).
**이 문장을 쓴다:** "두 사람이 남긴 말과 사진은 고치지 않고 실었어요. 온도록이 쓴 문장은 발행 노트에 따로 적었어요."
디자인 세션이 다듬은 문장이 오면 그 문장으로 바꾼다(뜻은 이대로). 문구는 한 곳(상수)에 둔다.

## 지켜야 할 것

- **CLAUDE.md 절대 규칙 8개 그대로** — 특히 **3(인쇄 PDF 비노출, `issues_public`만)**. 커밋·푸시는 사람
- **새 의존성 없음** — 핀치 줌은 이미 있는 `react-native-gesture-handler` + Reanimated로, PDF는 서명 URL을 `Linking`으로 연다. 파일 저장·공유 라이브러리를 들이지 않는다
- **서명 URL을 로그·저장소·보고에 남기지 않는다**(보고에는 HTTP 상태만)
- 색·서체 확인 항목은 `56-`과 같다 — 새로 만든·바꾼 파일에 하드코딩 색 0 · `fontWeight` 0 · `textFaint`는 비활성 컨트롤 글자에만 · `lilac` 12pt 이하 글자 0(완료 보고 확인 항목, 새 정적 규칙 아님)
- **속표지는 종이 바탕**(`paper`·`paperInk`·`paperMute`) — 밤에서 종이로 넘어가는 순간이다. **`moon`은 발행된 호·Vol·이 순간에만**
- 나가는 길: 뷰어 시트는 ✕(R18-2). 블러 없음, 금지 모션(카운트업·진행률 채움·스피너) — 다음 호 카드의 진행률도 **채움 애니메이션 없이** 정지 값
- 상대의 기록은 읽기만. RLS 그대로. 원격 조회는 **시험 계정의 사용자 권한으로**(service_role 아님)
