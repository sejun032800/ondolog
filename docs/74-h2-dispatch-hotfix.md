## 1. 고칠 것

### ① D1 — 같은 실행 안 재로그인에서 실패 화면이 덮임

**알려진 사실**
- 처음 설치한 뒤의 첫 로그인, 앱 종료 → 재실행은 성공한다.
- 같은 실행 안에서 로그아웃 → 다시 로그인하면 "로그인하지 못했어요"가 뜬다.
- 그 상태에서 앱을 백그라운드로 보냈다가 다시 열면 메인으로 들어온다. 즉 **세션 교환은 성공했고, 화면만 실패로 덮인다.**
- 11/9 녹화에서는 실패 화면과 "이미 가입한 계정이에요" 알림이 함께 떴다.

| # | 할 일 |
|---|---|
| a | **사용자를 막지 않는 안전장치**: 실패 화면을 띄우기 전에 현재 세션이 유효한지 확인한다(`getSession` · 필요하면 `getUser`). 유효하면 실패 화면 없이 정상 흐름으로 보낸다(탈퇴 유예면 유예 화면, 아니면 메인). 실패 화면이 이미 떠 있는 동안에도 세션이 생기면 정상 흐름으로 넘어간다 |
| b | **원인 제거** — 아래 셋을 코드와 로그로 하나씩 판정하고, 해당하는 것을 고친다<br>1. 앱 링크 리스너(`appUrlOpen`)가 로그인할 때마다 다시 등록됨 → **앱 생애에 한 번만 등록**하고, 중복 등록을 막는 표시를 둔다<br>2. 시작 링크(`getLaunchUrl`)를 다시 읽어 지난 코드로 교환을 다시 시도함 → **시작 링크는 앱 생애에 한 번만** 처리한다<br>3. 같은 코드가 두 경로(리스너와 시작 링크, 또는 리스너 둘)로 들어와 두 번째 처리가 첫 번째 성공을 실패로 덮음 → 이미 성공한 로그인 위에 실패를 쓰지 않는다 |
| c | **시험 빌드 전용 진단 표시**: `build:trial`에서만 실패 화면 아래에 작은 글씨로 **실패 단계 이름**과 짧은 분류만 보인다. 단계 이름 예: 링크 받음 / 코드 교환 / 계정 마무리 / 상태 읽기. 분류 예: 교환 오류 종류, 몇 번째 처리인지. 코드 · 주소 · 토큰 · 이메일은 0이다. 운영 빌드(`build`)에서는 코드째 빠진다 |
| d | **시험**: 같은 실행에서 로그인 → 로그아웃 → 로그인 → 로그아웃 → 로그인(**두 번 반복**)과 탈퇴 → 로그인. 리스너 수가 늘 1인지, 시작 링크 처리 횟수가 1인지, 같은 코드가 두 번 와도 실패 화면이 0인지, 세션이 유효할 때 실패 화면이 0인지 본다. **이 시험이 지키는 것은 앱 쪽 절반**이라고 보고에 쓴다 |

### ② 피드 연결 전 (R30-3 · R78-3)

- 안내 카드 문구를 **"연인과 연결되면 기록할 수 있어요"**로 바꾼다. 보조 문장이 필요하면 보드 E13 문구를 쓰고, 없으면 지금 보조 문장을 유지한다.
- 흐린 + 버튼을 누르면 **이유 한 줄과 [초대하러 가기]**가 나온다. h1 기록 시트의 안내를 재사용한다. 눌러도 반응이 없는 상태는 0이어야 한다.
- 첫 기록 버튼 등 막아 둔 다른 진입점도 같은 반응을 보인다.
- 시험: 연결 전에 + 버튼을 누르면 이유와 초대 버튼이 보이고, 기록 저장 함수는 불리지 않는다.

### ④ 초기화 스크립트 사용성 (R78-3 · 실제로 막힌 두 곳)

- 사용자 조회가 실패했을 때 **넣은 키가 공개 키로 보이면** "서비스 키가 아니에요. 대시보드의 service_role(또는 Secret) 키를 넣어 주세요." 한 줄을 출력한다. 판별은 키 형식만 본다. JWT라면 `role` 값, 새 형식이라면 접두어로 판별한다. **키 값과 그 일부는 출력하지 않는다.**
- HANDOFF의 74-0 실행 안내를 바꾼다.
  - 환경 변수를 넣는 줄은 `$env:ONDOLOG_SUPABASE_SERVICE_ROLE_KEY = [Net.NetworkCredential]::new('', (Read-Host -AsSecureString)).Password`(주소도 같은 방식)로 쓴다. 붙여넣기는 마우스 오른쪽 클릭이라는 안내 한 줄을 단다.
  - `--allow-net=<프로젝트 ref>.supabase.co` 대신 Proteur가 ref를 직접 적지 않아도 되는 방식을 쓴다. 지금 Proteur는 `--allow-net`(전체)으로 돌렸다. 범위를 좁히고 싶으면 스크립트가 주소에서 호스트를 읽어 쓰게 하는 방법 등을 쓰고, 방식을 결정 기록에 남긴다.
  - "명령은 저장소 맨 위 폴더에서" 한 줄. 끝나면 PowerShell 창을 닫으라는 한 줄.
- 시험(원격 없음): 공개 키 형식이면 안내 한 줄이 나오고, 출력에 키 문자열이 0이다.
