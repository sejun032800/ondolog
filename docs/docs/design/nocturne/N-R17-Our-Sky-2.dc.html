C03 · 방금 잡은 말

  • 1{n} / {N} = 지금까지 잡은 말 전체 중 위치. 방금 잡은 말이 N번째(마지막)로 열립니다 → "3 / 3".
  • 2마지막 말이라 "다음 말 ›"은 흐리게(현재 C03에서 1/3일 때 "이전 말"이 흐린 것과 같은 규칙).
  • 문장 · 출처 표기("{이름} · {M}월 {D}일 밤 {h}시 {m}분") · 채팅에서 보기 · 안내 · 공유 버튼 없음 — 모두 현재 그대로. 원문은 자르지 않고 길면 이 화면 안에서 스크롤.
