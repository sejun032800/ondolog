## 6. 종합 — 무엇이 기획만 있고 무엇이 구현만 있는가

**기획만 있고 구현 없음** (Phase 7 이후 착수 대상, 문제 아님)
- Phase 2 확장 코너 4종 전체(스키마·타입·생성코드·UI)
- 코너 12종 생성 파이프라인 전체(MVP 5종 포함) — CORNER_CONTENT.md의 TS
  타입·Zod 스키마는 있지만 이를 소비하는 생성 코드(`src/engine/corners/`)는
  빈 디렉터리
- 매거진 탭 재설계(실루엣+제작 진행률)
- 엔진 4곳 자리표시자 공식

**구현은 있는데 문서가 아직 못 따라온 부분은 없음** — 오늘 문서 갱신은
전부 기획을 코드보다 앞서 정교화하는 방향이었고, 코드 쪽에서 문서에 없는
임의 구현이 발견되진 않았다(캐릭터화 흔적 0건이 이를 방증).

**다음으로 넘어가기 전 확인할 것 3가지**
1. `018_realtime_publication.sql`이 실제 원격(Supabase)에 적용됐는지 —
   로컬 파일 존재와 원격 적용은 별개다.
2. 엔진 4곳 자리표시자 — Phase 7(코너 생성) 착수 전 반드시 해소 필요
   (§3).
3. Phase 6 잔여 5단계(SDK 재빌드부터) — ROADMAP이 지목한 "재빌드 후
   5가지 동시 첫 검증" 리스크가 아직 유효하다.
