MOTION · MAIN 유성이 지나가는 밤

느리게, 드물게, 의미 있게.
하늘은 숨 쉬듯 움직이고, 유성은 가끔만 떨어져요.

움직이는 것 — 뒤에서 앞으로

  • 하늘 — 40초에 24px 위아래로 흘러요(왕복). 거의 안 보일 만큼
  • 별 26개 — 2.8~6.4초 주기로 각자 반짝임. 색은 lilac · rose · moon · mist 빛
  • 유성 — 0.96초 동안 가속하며 지나가고 꼬리부터 사라져요
  • 숫자 — 유성이 지나간 직후 빛이 한 번 짙어졌다 돌아와요(숫자는 세지 않음)
  • 손잡이 — 3.2초마다 4px 내려갔다 올라와 '끌어내리기'를 알려줘요

유성

  • 유성 — 흰빛 · 달빛 · 라일락빛. 실제 앱에서는 6~14초 사이 무작위로 하나. 보드에서는 12초 루프에 3개
  • 표시나 라벨 없이 계속 나타났다 사라져요. 지나가는 유성을 누르면 C03 '떨어진 말'

모션 토큰

  • 등장 ease cubic-bezier(.2,.8,.2,1) · 0.7~0.8초 · 순차 간격 80ms
  • 유성 0.96초 — 처음 0.36초에 28%, 이후 가속해 끝까지, 마지막 0.3초에 꼬리부터 사라짐
  • '동작 줄이기' 설정: 유성 · 별 · 하늘 흐름 끔, 등장은 0.2초 페이드만
  • 저전력 모드 · 화면이 안 보일 때 · 하늘을 끌어내리는 중에는 루프 멈춤

구현

  • Reanimated withRepeat · withDelay · withSequence, 별은 Skia Canvas 한 장(뷰 26개 대신)
  • 유성은 expo-linear-gradient 막대 + 머리 점, 시작 위치 · 각도 · 길이는 매번 무작위
