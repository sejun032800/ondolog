## 개발 참고(85- 다음 트랙)

- 원본은 `<img>` 두 장 띠 + `translate3d`만(배경 위치 애니메이션 금지). 텍스처 3896px — V40 한도 4096 안.
- 85-b의 방향 계산에서 쓰는 것은 바라보는 방향(yaw) 하나. 들어갈 때의 yaw를 0°로 둡니다.
- 지평선 실루엣은 둘레 3116.8pt의 이어지는 path(0~390pt = C01 path). 보드 스크립트 `groundPath()`가 모양 명세입니다.
- 원본을 다시 만들 때: `python make_sky_pano.py <sky_world.jpg> <출력>` (numpy · Pillow, 시드 고정이라 같은 그림).
