# 폰트 라이선스

조판에 실제로 쓰는 폰트만 담았다. 둘 다 **PDF 임베드가 허용**된다.

| 파일 | 서체 | 라이선스 | 임베드 | 쓰는 곳 |
|---|---|---|---|---|
| `Pretendard-Regular.otf` | Pretendard | SIL Open Font License 1.1 | 허용 | 라벨 · 숫자 · 킥커 · 캡션 |
| `Pretendard-Medium.otf` | Pretendard | SIL OFL 1.1 | 허용 | 시각 · 강조 라벨 |
| `Pretendard-Bold.otf` | Pretendard | SIL OFL 1.1 | 허용 | "N월호" · 표 머리 · 출처 막대 |
| `MaruBuri-ExtraLight.otf` | 마루 부리 | SIL OFL 1.1 | 허용 | 표지 표제(대형 활자) |
| `MaruBuri-Light.otf` | 마루 부리 | SIL OFL 1.1 | 허용 | 기사 제목 · 리드 |
| `MaruBuri-Regular.otf` | 마루 부리 | SIL OFL 1.1 | 허용 | 인용 원문 · 워드마크 · 목차 코너명 |
| `MaruBuri-SemiBold.otf` | 마루 부리 | SIL OFL 1.1 | 허용 | 예비(현재 미사용 — 필요 없으면 빼도 된다) |

- **Pretendard** — ⓒ 길형진(orioncactus). SIL OFL 1.1.
- **마루 부리(MaruBuri)** — ⓒ NAVER. SIL OFL 1.1. 네이버 글꼴 저작권 안내를 따른다.

SIL OFL 1.1은 상업적 사용·임베드·재배포를 허용한다. 다만 **폰트 파일 자체를 판매할 수 없고**,
예약 글꼴 이름(Reserved Font Name)을 쓴 파생본을 만들 수 없다. 조판·PDF 임베드는 둘 다 해당하지 않는다.

> 기존 발행물 PDF는 글리프가 Type3로 변환되어 있어 원본 서체 이름을 되읽을 수 없다.
> 위 구성은 P1 보드의 `@font-face` 선언과 디자인 문법(§0-4 잉크 3단계)에서 복원한 것이다.
> 조판 결과가 기존 PDF와 미세하게 다르면 여기를 먼저 본다.
