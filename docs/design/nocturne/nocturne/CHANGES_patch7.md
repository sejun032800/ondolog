## 1-1. 탭 아이콘 — 명세로

`icons/`에 SVG 원문 다섯 개와 명세서를 넣었다. **이 값이 구현 명세다.**

### 색 토큰 대응 (요청 1-1 ②)

| 쓰임 | 값 | 토큰 |
|---|---|---|
| 활성 아이콘 | `#F4B9C8` | `rose` |
| 활성 글자 | `#F3EFF7` | `text` |
| 비활성 | `#9C93B4` | `textMute` |
| 바 배경 | `rgba(10,8,20,.92)` | **없음** — `ink` 92% |
| 바 테두리 | `rgba(243,239,247,.08)` | **없음** — `text` 8% |
| 활성 글로우 | `rgba(244,185,200,.55)` | **없음** — `rose` 55% |

**없는 셋은 새 색이 아니라 기존 토큰의 투명도 변형이다.**
하드코딩을 피하려면 `alpha(ink, .92)` 같은 **투명도 유틸**이 색 토큰을 늘리는 것보다 낫다.
굳이 이름을 붙인다면 `tabBarSurface` · `tabBarBorder` · `tabActiveGlow`지만,
셋 다 탭 바 한 곳에서만 쓰여 토큰이라기보다 컴포넌트 값이다. **값 자체는 위 표가 확정이다.**

## 1-3. 보드에 없던 상태 — 판단한 것

- **ⓒ A18** — 자기 코드만 따로. 나머지 무효는 **한 문구**. 구분하면 코드를 넣어 보며 남의 코드 상태를 떠볼 수 있다
- **ⓔ H14 상대 쪽** — 버튼만 빼지 않는다. **주어가 바뀐다**("내 기록" → "상대 기록"). 버튼만 빼면 상대가 자기 기록이 지워지는 줄 안다. 빈 버튼 자리에는 **왜 없는지**를 적는다
- **ⓕ H16** — 유예 중 로그인하면 **이 화면이 먼저**. 설정 안에 있으면 남은 날짜를 모르고 지나친다
- **ⓖ 문구 입력** — H14 `해제합니다` · H16 `탈퇴합니다`. **달라야 한다** — 같으면 한 번 쳐 본 손이 다른 화면에서도 그대로 움직인다. 안전장치가 타자 연습이 되면 안 된다
  - MASTER 9-6의 **발행물 PDF 저장 안내**도 두 화면에 모두 뒀다. H14에는 있었고 H16 확인에는 없었다
- **ⓐ B01** — 온도 바로 아래 세로 괘선 안쪽. 조건 셋 중 하나라도 없으면 블록째 빠진다
- **ⓑ A11** — 제목·부제가 다르고 하단 동의 안내는 숨긴다. 이 길에선 동의한 적이 없다
- **ⓓ H04** — 안내는 **날짜 줄 바로 아래**. 저장 버튼 옆이 아니다 — 바꾸기 전에 읽혀야 한다

## 3. 한 가지 여쭙니다 — ⓐ의 말투

MASTER 9-2의 두 문장은 **합니다체**인데 앱의 다른 문장은 전부 **해요체**다.
고정 문장이라 그대로 뒀다. 해요체로 맞추려면
"온도가 잘 맞는 유형일수록 시작 온도가 조금 **높아요**. / 나머지는 두 사람이 **만들어가요**."
어느 쪽으로 할지 정해 주시면 맞추겠다.
