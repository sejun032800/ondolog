## 왜 다시 손댔나

patch4에서 Components 보드에 탭 아이콘을 그려 넣었는데, **실제 화면 109장과 달랐다.**

| | patch4 (내가 그린 것) | 실제 화면 | patch6 |
|---|---|---|---|
| 메인 아이콘 | 별 | **초승달** | 초승달 |
| 피드 아이콘 | 2×2 격자 | **사진 틀 + 능선** | 사진 틀 + 능선 |
| 활성 표시 | 별빛 점 하나 | **장밋빛 아이콘 + 글로우**(점 없음) | 장밋빛 + 글로우 |

Components 보드의 설명 "활성 = 별빛 점 하나"도 화면과 달랐다 — 함께 고쳤다.

> **화면 109장은 처음부터 아이콘 탭이었다.** R23-7이 가리킨 "텍스트 탭"은
> 보드의 **설명 문구**였지 화면이 아니었다. patch4는 설명만 고치면 됐는데,
> 그림까지 그리면서 화면을 보지 않고 그렸다.
