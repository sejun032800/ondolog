## 색 — 토큰 대응 (요청 1-1 ②)

| 쓰임 | 값 | Tokens 보드의 토큰 | 비고 |
|---|---|---|---|
| 활성 아이콘 | `#F4B9C8` | **`rose`** | 있음 |
| 활성 글자 | `#F3EFF7` | **`text`** | 있음 |
| 비활성 아이콘·글자 | `#9C93B4` | **`textMute`** | 있음 |
| 바 배경 | `rgba(10,8,20,.92)` | **없음** | `ink #0A0814`의 92% — 아래 참고 |
| 바 테두리 | `rgba(243,239,247,.08)` | **없음** | `text #F3EFF7`의 8% |
| 활성 글로우 | `drop-shadow(0 0 7px rgba(244,185,200,.55))` | **없음** | `rose`의 55% |

**토큰에 없는 셋은 전부 기존 토큰의 투명도 변형**이다. 새 색이 아니다.
앱이 하드코딩을 피하려면(R20-6) 두 가지 길이 있다.

1. **투명도 유틸**을 두고 `alpha(ink, .92)`처럼 쓴다 — 새 색 토큰이 늘지 않는다. **이 쪽을 권한다.**
2. 굳이 이름을 붙인다면 `tabBarSurface` · `tabBarBorder` · `tabActiveGlow`.
   다만 이 셋은 탭 바 한 곳에서만 쓰여서, 토큰이라기보다 컴포넌트 값이다.

어느 쪽으로 할지는 개발이 정하면 맞추겠다. **값 자체는 위 표가 확정이다.**
