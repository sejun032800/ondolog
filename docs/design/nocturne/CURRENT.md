## 1. 덮인 화면 다섯 장 — PNG는 아직 옛 판

patch5가 바꾼 내용이 아직 `screens/`의 PNG에 반영되지 않았다.
**화면 그림과 보드가 다르면 보드를 따른다**(R20-8 — `N-R31-App-Fixes`).

| 화면 | 바뀐 것 |
|---|---|
| `E01.png` 피드 | 머리 "기록 4" → **"메모 4"** |
| `E03.png` 데이트 상세 | 사진·메모에 **`⋯` 삭제 진입점** + 확인 시트 |
| `E10.png` 사진 직접 추가 | **없앤다** — 시스템 사진 선택기로 대체 |
| `E11.png` 데이트 기록 쓰기 | **시간 칸이 조건부**(stop 없음 + 촬영 시각 전무일 때만), 안내 문구 2종 |
| `D10.png` 속표지 | **고지 문구 교체**(R31-9) |

**patch7이 덮은 화면은 더 많다** — B01 · A11 · A18 · H04 · H14 · H16 · A12 · F02 · H05 · H11.
**patch8은 A15 · B01의 문장을 덮는다.**
모두 `N-R43-App-States` 보드를 따른다.

PNG 재출력은 라이브 캔버스의 화면 원본이 있어야 한다 — 이 묶음에는 없다.
1-3·2번이 반영될 때 한 번에 하면 된다(PM 요청서 §4).

## 2. 보드가 화면과 달랐던 것 — 고침 (patch6)

patch4로 Components 보드에 탭 아이콘을 그려 넣었는데, **실제 화면 109장과 달랐다.**

| | patch4(내가 그린 것) | 실제 화면 | patch6 |
|---|---|---|---|
| 메인 아이콘 | 별 | **초승달** | 초승달 |
| 피드 아이콘 | 2×2 격자 | **사진 틀 + 능선** | 사진 틀 + 능선 |
| 활성 표시 | 별빛 점 하나 | **장밋빛 아이콘 + 글로우**(점 없음) | 장밋빛 + 글로우 |

Components 보드의 "활성 = 별빛 점 하나"라는 설명도 **화면과 달랐다** — 함께 고쳤다.
`N-R31-App-Fixes`의 E01 탭 바도 같은 기준으로 맞췄다.

> **화면 109장은 처음부터 아이콘 탭이었다.** R23-7이 가리킨 "텍스트 탭"은
> 보드의 **설명 문구**였지 화면이 아니었다.

## 3. 다섯 아이콘 (화면 기준)

선 아이콘 · 18px · `viewBox 24` · `stroke-width 1.6` · `currentColor`.

| 탭 | 모양 |
|---|---|
| 메인 | 초승달 |
| 채팅 | 말풍선 (꼬리 왼쪽 아래) |
| 피드 | 사진 틀 + 능선 |
| 매거진 | 펼친 책 |
| 설정 | 가로 슬라이더 3줄 + 손잡이 |

활성: 아이콘 `#F4B9C8` + `drop-shadow(0 0 7px rgba(244,185,200,.55))`, 글자 `#F3EFF7` 600.
비활성: 아이콘·글자 `#9C93B4` 500. 바는 하단에서 12px 띄운 섬, 높이 64px, 반경 22px.

**보드의 SVG가 곧 구현 명세다.** `react-native-svg`로 디자인이 그린 아이콘만 인라인으로 쓴다
(아이콘 팩·아이콘 폰트 금지 — R18-3, `53-` 구현 완료).
원문은 `icons/tab_icons.md`와 `icons/tab-*.svg` 다섯 개에 있다. 앱의 아이콘이 다르면 **이 값으로 맞춘다.**

색 토큰 대응도 `icons/tab_icons.md`에 적었다 — 활성 `rose` · 글자 `text` · 비활성 `textMute`,
바 배경·테두리·글로우 셋은 토큰에 **없고** 기존 토큰의 투명도 변형이다.
