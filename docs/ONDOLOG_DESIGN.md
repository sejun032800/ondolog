# ONDOLOG 디자인 시스템

> **기준은 실제 발행물이다.** `ONDOLOG_Corners_digital.pdf`(본지 라이트)와
> `ONDOLOG_Corners_night_digital.pdf`(본지 다크)가 이 문서의 원본이며,
> 앱 UI는 그 지면을 화면으로 옮긴 것이다.
>
> `ui-builder`와 `corner-pipeline`이 공유하는 유일한 시각 기준.
> 이 문서에 없는 색·서체·간격을 만들지 않는다.

---

## 0. 시그니처 — 잉크 농도가 개입도를 말한다

발행물 목차에 이렇게 적혀 있다.

> 코너마다 잉크 색이 다릅니다. 지표를 다루는 코너는 세이지, 이야기를 다루는 코너는 먹, 두 사람이 실제로 주고받은 말을 그대로 싣는 코너는 가장 옅은 담묵을 씁니다.
> **색이 옅어질수록 온도록이 문장에 손을 덜 댔다는 뜻입니다.**

이것이 ONDOLOG를 기억하게 만드는 단 하나의 장치다. 장식이 아니라 **제품 윤리의 시각화**다. Part 3-7의 "원문 우선, AI는 맥락만"이 색 체계 자체가 되었다.

| 잉크 | 개입도 | 대상 | 코너 |
|---|---|---|---|
| **세이지** (다크: 샴페인) | 가장 높음 — 온도록이 계산한 값 | 지표·수치 | 연애 DNA, 연애리그 |
| **먹** | 중간 — 온도록이 쓴 문장 | 서사·기사 | 데이트 아카이브, 이달의 우리 |
| **담묵** | 가장 낮음 — 두 사람의 말 그대로 | 원문 인용 | 다정한 말들, 유저 메모 |

**규칙**

- 이 위계는 **앱에도 그대로 적용**한다. 채팅 인용은 담묵, AI 서사는 먹, 온도·일치율은 세이지/샴페인
- 개입도가 낮을수록 옅다. 직관과 반대일 수 있으나 **먹을 덜 묻혔다는 인쇄 은유**가 근거다
- 이 규칙을 어기면 시스템 전체가 의미를 잃는다. 예외를 만들지 않는다

> 이전 버전의 "온도 크로마(온도에 따라 배경색 이동)"는 **폐기한다.** 시그니처는 하나여야 하고, 잉크 위계가 더 강하다.

### 1-3. 별지 (연애리그)

발행물에서 연애리그는 **별지**다. 본지와 반대 색 종이를 쓴다. 잡지가 특집면에 다른 지질을 쓰는 관행이다.

| 본지 모드 | 별지 |
|---|---|
| 라이트 (`#F0EDE6`) | **어두운 지면** `#2E2B26`, 잉크 `#EDE9DE` |
| 다크 (`#151B2D`) | **밝은 지면** `#EFEDE3`, 잉크 `#3A3732` |

**앱 적용**: 연애리그 관련 화면(스탯 카드, 매치 리포트)은 별지 팔레트를 쓴다. 화면을 옮겼을 때 지면이 뒤집히는 감각이 발행물의 별지 경험을 그대로 옮긴다.

### 1-4. 4기후 (36종 라벨 전용)

라벨 배지와 결과 카드에만 쓴다. 본문·크롬에 쓰지 않는다.

| 기후 | 라이트 | 다크 |
|---|---|---|
| `ember` 안정 | `#A0664A` | `#C08A64` |
| `flare` 불안 | `#A6505E` | `#C97785` |
| `frost` 회피 | `#5B7285` | `#8098AC` |
| `tide` 혼란 | `#3F6B64` | `#5E9187` |

### 1-5. 금지

- 순수 `#000` / `#FFF`
- 그라디언트 (표지 사진 제외)
- UI 크롬(버튼·탭바)에 액센트·기후색 사용
- 잉크 위계를 무시한 색 지정

## 2. 타이포그래피

### 2-1. 서체

| 역할 | 서체 | 용도 |
|---|---|---|
| **한글 디스플레이·본문** | 명조 계열 세리프 | 제목, 기사 본문, 인용 |
| **한글 UI** | Pretendard | 버튼, 라벨, 캡션, 입력 |
| **영문 키커** | 세리프, 넓은 자간 | `D A T E  A R C H I V E` |
| **숫자** | 명조 세리프, Oldstyle | 온도, 일치율, 스탯, 호수 |

> ✅ **확정**: 세리프는 **MaruBuri(마루부리)**, UI 산세리프는 **Pretendard**. 영문도 MaruBuri 라틴 글리프를 쓴다. 파일·웨이트·RN 적용법은 **§11** 참조.

### 2-2. 스케일

| 토큰 | 크기 | 행간 | 서체 | 용도 |
|---|---|---|---|---|
| `numeral-xl` | 64 | 68 | 세리프 | 온도, 일치율 |
| `numeral` | 32 | 38 | 세리프 | 스탯, 호수, D+N |
| `display` | 30 | 42 | 세리프 | 화면 제목 |
| `headline` | 21 | 32 | 세리프 | 섹션 제목 |
| `body-serif` | 16 | 29 | 세리프 | 기사 본문, 인용 |
| `title` | 16 | 24 | Pretendard SemiBold | UI 항목 |
| `body` | 15 | 24 | Pretendard | UI 본문 |
| `caption` | 12 | 18 | Pretendard | 메타데이터 |
| `kicker` | 10 | 14 | 세리프, `letterSpacing 0.30em`, 대문자 | 섹션 라벨 |

**자간 규칙** — 발행물의 특징적 처리다.

| 대상 | 자간 |
|---|---|
| 영문 키커 | `0.30em` |
| 영문 라벨 (`K E E L E M B E R`) | `0.22em` |
| 한글 키커 (`다 정 한 말 들`) | `0.18em` |
| 본문 | `0` |

### 2-3. 숫자 표기

발행물의 `74.2` 처리를 따른다. **정수부가 크고 소수부가 작다.**

```
74.2  →  74 (numeral-xl) + .2 (numeral-xl의 45%)
```

온도(`38.2°`)도 동일. 도 기호는 소수부와 같은 크기.

## 3. 간격과 선

### 3-1. 4pt 그리드

| 토큰 | s1 | s2 | s3 | s4 | s5 | s6 | s7 | s8 |
|---|---|---|---|---|---|---|---|---|
| 값 | 4 | 8 | 12 | 16 | 24 | 32 | 48 | 64 |

### 3-2. 판면

| 항목 | 값 |
|---|---|
| 좌우 여백 | `24` |
| 섹션 간격 | `s7` (48) |
| 지면 상단 여백 | `s6` (32) |

**여백을 아끼지 않는다.** 발행물의 인상은 대부분 여백에서 나온다. 조밀하게 채우면 신문이 되고, 신문은 우리가 아니다.

### 3-3. 선

| 종류 | 두께 | 색 | 용도 |
|---|---|---|---|
| `hairline` | `hairlineWidth` | `rule` | 목록 구분 |
| `section` | `1` | `rule` | 섹션 경계 |
| `masthead` | `1.5` | `rule-strong` | **지면 상단**. 발행물 러닝헤드 아래 선 |

### 3-4. 모서리·그림자

| 항목 | 규칙 |
|---|---|
| `radius` | **0** — 지면에는 둥근 모서리가 없다 |
| `radius-touch` | **2** — 버튼·입력창만 |
| 그림자 | **전면 금지** |

카드를 띄우지 않는다. 분리는 선과 여백으로 한다.

## 4. 레이아웃 패턴

### 4-1. 지면 헤더 (모든 화면 공통)

발행물의 러닝헤드를 그대로 옮긴다.

```
데 이 트 아 카 이 브              연남동 · 2026년 8월
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

좌: 화면명(한글 키커, 자간 0.18em) / 우: 맥락 정보(caption) / 아래: masthead 선

### 4-2. 기사형 화면

```
A R T I C L E  O N E  ·  2026.08.19     ← 영문 키커
Y E O N N A M - D O N G                 ← 지역 (영문, 자간)

스파이더맨과                            ← display
케이크 사이

오후 두 시에 시작해...                   ← body-serif
```

### 4-3. 지표형 화면

```
        74.2                          ← numeral-xl, accent
   이달의 일치율   지난달 71.9 ▲2.3      ← headline + caption

성격 기저값        70.8   고정 · 성격 검사 기반
─────────────────────────────────────
대화 변동분        +3.4   온기 · 리듬 · 상호성
─────────────────────────────────────
합계              74.2   하한 50 · 상한 100
```

수치는 항상 **액센트 색**, 라벨은 `ink-mute`, 근거는 `caption`.

### 4-4. 인용형 화면 (담묵)

```
아침 출근길에 오간 대화                  ← title, ink-mute
— 2026.08.22 09:20, 아침 대화 중         ← caption

  세준                                  ← caption, ink-faint
  오늘 비 온대. 우산 챙겼어?              ← body-serif, ink-wash

      서영                              ← 들여쓰기로 화자 구분
      응 챙겼어. 너도 감기 조심해
```

**발행물의 처리를 그대로 따른다** — 말풍선을 쓰지 않고 **들여쓰기와 화자 라벨**로 구분한다. 채팅 UI가 아니라 지면이다.

> 단, 채팅 탭(Phase 5)의 실시간 대화는 예외다. 실제 대화는 말풍선이 기능적으로 옳다. **인용된 대화**만 이 규격을 따른다.

### 4-5. 두 사람

커플 데이터는 항상 좌우. **나는 왼쪽, 상대는 오른쪽.** 모든 화면에서 고정.

```
세준                        서영
K E E L E M B E R           M U S E F L A R E
온돌 같은 원칙주의자          열대야 같은 낭만주의자
ISTJ · 애니어그램 1 · 안정형   ISFP · 애니어그램 4 · 불안형
```

### 4-6. 축 비교 (연애 DNA)

```
개방성   ────●───────○────    29 / 71
        새로운 곳을 찾는 쪽은 서영입니다

● 나(채움)   ○ 상대(빈 원)
```

채움/빈 원으로 두 사람을 구분한다. **색으로 구분하지 않는다.**

## 5. 컴포넌트

### 5-1. 버튼

| 종류 | 라이트 | 다크 |
|---|---|---|
| Primary | `ink-full` 배경 / `paper` 글자 | 동일 |
| Secondary | 투명 / `ink-full` 테두리 1px | 동일 |
| Text | 텍스트 + 밑줄 | 동일 |

높이 `52`, `radius-touch`(2), `title` 서체. **액센트 색을 쓰지 않는다.**

### 5-2. 탭바

| 항목 | 규칙 |
|---|---|
| 배경 | `paper` |
| 상단 | `hairline` |
| 라벨 | `caption`, 한글, 자간 `0.06em` |
| 아이콘 | 선형, 굵기 1.25px. 채움 금지 |
| 활성 | `ink-full` / 비활성 `ink-faint` |

### 5-3. 서재 (매거진 목록)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
매 거 진                최신순 ▾
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌────────┐  ┌────────┐
│        │  │        │      ← 표지 (A4 비율 1:1.414)
│ Vol.02 │  │ Vol.01 │
└────────┘  └────────┘
─────────────────────       ← 선반 선
2026.09       2026.08
```

표지 아래 얇은 선으로 **책장 선반**을 만든다. 그림자로 띄우지 않는다.

### 5-4. 유형 라벨

```
K E E L E M B E R          ← title, 기후색, 자간 0.22em
온돌 같은 원칙주의자          ← headline, ink-full
늘 같은 온도로 곁에 있는 사람  ← body, ink-mute
━━                         ← 기후색 1.5px, 길이 24
```

배경 틴트를 쓰지 않는다. **선 하나로 색을 표시한다.**

### 5-5. 온도 히어로 (메인 탭)

```
O U R  T E M P E R A T U R E     ← kicker, ink-mute

        38.2°                    ← numeral-xl, accent

    D+298 · 온돌커플              ← caption
```

**미산출 상태**

```
O U R  T E M P E R A T U R E

  아직 온도를 잴 기록이 없어요      ← headline, ink-mute
```

숫자 자리에 `--`나 `0`을 넣지 않는다.

## 6. 모션

발행물은 움직이지 않는다. 앱도 최소한만 움직인다.

| 허용 | 규격 |
|---|---|
| 화면 전환 | 180ms, ease-out |
| 모드 전환 | 300ms 크로스페이드 |
| 버튼 눌림 | opacity 0.6, 즉시 |

**단 하나의 연출**: 새 호 발행 시 표지가 나타나는 순간. 여기에만 힘을 준다.

`prefers-reduced-motion` 시 전환 없이 즉시.

### 9-2. 잉크 위계 API

컴포넌트가 색을 직접 고르지 않고 **내용의 성격을 선언**한다.

```typescript
type InkLevel = 'metric' | 'narrative' | 'verbatim';

// 사용
<Text style={ink('verbatim')}>오늘 비 온대. 우산 챙겼어?</Text>
<Text style={ink('narrative')}>영화가 끝나고 근처에서 저녁</Text>
<Text style={ink('metric')}>74.2</Text>
```

이렇게 하면 위계를 어기기 어려워진다. 하드코딩된 색은 리뷰에서 걸러낸다.

### 9-3. 절대 규칙

- 이 문서에 없는 색·크기를 하드코딩하지 않는다
- 그림자를 쓰지 않는다
- UI 크롬에 액센트·기후색을 쓰지 않는다
- 원문 인용은 반드시 `verbatim`(담묵), AI 서사는 `narrative`(먹)
- 인용 대화에 말풍선을 쓰지 않는다 (§4-4)

## 11. 서체 — 확정

### 11-1. 파일

| 서체 | 조달 | 라이선스 |
|---|---|---|
| **MaruBuri** | 네이버 클로바. TTF 5웨이트 | OFL, 임베딩 자유 |
| **Pretendard** | github.com/orioncactus/pretendard | OFL |

**앱에 넣을 파일 (TTF)**

```
assets/fonts/
  MaruBuri-Light.ttf        # 숫자, 디스플레이
  MaruBuri-Regular.ttf      # 제목, 본문, 인용
  MaruBuri-SemiBold.ttf     # 강조 (드물게)
  Pretendard-Regular.ttf    # UI 본문
  Pretendard-SemiBold.ttf   # UI 강조
```

**ExtraLight·Bold는 쓰지 않는다.** 웨이트를 3개로 제한하는 것이 지면의 절제된 인상을 만든다.

### 11-2. 영문도 MaruBuri를 쓴다

발행물과 앱이 같은 서체여야 하므로, **영문 키커·라벨도 MaruBuri의 라틴 글리프**를 쓴다. 별도 영문 세리프를 추가하지 않는다.

근거 세 가지 — ① 발행물이 그렇게 조판되었다 ② 폰트 파일이 늘지 않는다 ③ `K E E L E M B E R` 같은 라벨이 한글 제목과 같은 계열로 읽힌다.

### 11-3. RN에서 웨이트를 다루는 법

**`fontWeight`를 쓰지 않는다.** 커스텀 폰트에서 `fontWeight`는 Android에서 무시되거나 가짜 볼드를 만든다. **반드시 `fontFamily`로 웨이트를 지정한다.**

```typescript
// ✗ 금지
{ fontFamily: 'MaruBuri', fontWeight: '300' }

// ✓ 올바름
{ fontFamily: 'MaruBuri-Light' }
```

### 11-4. 토큰별 폰트 확정

| 토큰 | fontFamily | fontSize | lineHeight | letterSpacing(pt) |
|---|---|---|---|---|
| `numeral-xl` | `MaruBuri-Light` | 64 | 68 | -1 |
| `numeral` | `MaruBuri-Light` | 32 | 38 | -0.5 |
| `display` | `MaruBuri-Regular` | 30 | 42 | -0.3 |
| `headline` | `MaruBuri-Regular` | 21 | 32 | 0 |
| `body-serif` | `MaruBuri-Regular` | 16 | 29 | 0 |
| `quote` | `MaruBuri-Regular` | 16 | 29 | 0 |
| `title` | `Pretendard-SemiBold` | 16 | 24 | 0 |
| `body` | `Pretendard-Regular` | 15 | 24 | 0 |
| `caption` | `Pretendard-Regular` | 12 | 18 | 0 |
| `kicker-en` | `MaruBuri-Regular` | 10 | 14 | **3.0** |
| `kicker-ko` | `MaruBuri-Regular` | 11 | 16 | **2.0** |
| `label-en` | `MaruBuri-Regular` | 16 | 22 | **3.5** |

### 11-5. letterSpacing 단위 — 중요

**RN의 `letterSpacing`은 em이 아니라 pt다.** §2-2의 em 값을 그대로 쓰면 자간이 30배가 된다.

```
letterSpacing(pt) = fontSize × em
```

| §2-2 표기 | fontSize | RN 값 |
|---|---|---|
| 키커 `0.30em` | 10 | **3.0** |
| 한글 키커 `0.18em` | 11 | **2.0** |
| 영문 라벨 `0.22em` | 16 | **3.5** |

§11-4 표의 값이 이미 변환된 값이다. **그 값을 그대로 쓴다.**

### 11-6. 폰트 로드

```typescript
// app/_layout.tsx
import { useFonts } from 'expo-font';

const [loaded] = useFonts({
  'MaruBuri-Light':      require('../assets/fonts/MaruBuri-Light.ttf'),
  'MaruBuri-Regular':    require('../assets/fonts/MaruBuri-Regular.ttf'),
  'MaruBuri-SemiBold':   require('../assets/fonts/MaruBuri-SemiBold.ttf'),
  'Pretendard-Regular':  require('../assets/fonts/Pretendard-Regular.ttf'),
  'Pretendard-SemiBold': require('../assets/fonts/Pretendard-SemiBold.ttf'),
});
if (!loaded) return null;
```

> 폰트는 네이티브 자산이다. **Dev Build 재빌드가 필요**하다. Phase 6 일괄 빌드 전까지는 로드 코드만 넣고 시스템 폰트로 폴백한다.

### 11-7. 소수부 45% 구현

`74.2`의 `.2`를 작게 쓰는 처리(§2-3).

```tsx
function Numeral({ value }: { value: number }) {
  const [int, dec] = value.toFixed(1).split('.');
  return (
    <Text style={t.numeralXl}>
      {int}
      <Text style={{ fontSize: t.numeralXl.fontSize * 0.45 }}>.{dec}</Text>
    </Text>
  );
}
```

중첩 `<Text>`는 베이스라인을 자동으로 맞춘다. 별도 정렬이 필요 없다.
온도(`38.2°`)는 `°`도 소수부와 같은 크기로 이어 붙인다.

## 12. 아이콘 — 쓰지 않는다

**탭바를 포함해 앱 전체에 아이콘을 쓰지 않는다.** 한글 텍스트 라벨만 쓴다.

근거 세 가지.

| 근거 | 내용 |
|---|---|
| 지면 일관성 | 발행물에 아이콘이 하나도 없다 |
| 의존성 | 아이콘 라이브러리는 `react-native-svg`(네이티브)를 끌고 와 재빌드를 유발한다 |
| 차별성 | 아이콘 탭바는 모든 앱의 기본값이다. 텍스트 탭바가 이 앱을 다르게 만든다 |

**예외**: 기능적으로 필수인 기호는 문자로 대체한다.

| 용도 | 기호 |
|---|---|
| 정렬 토글 | `▾` |
| 증감 | `▲` `▼` |
| 이동 | `→` |
| 닫기 | `✕` |
| 뒤로 | `←` |

| 항목 | 규격 |
|---|---|
| 말풍선 | `radius-touch`(2). 둥글게 하지 않는다 |

| 상대 메시지 | `paper-alt` 배경 / `ink-full` 글자, 좌측, `rule` 테두리 1px |

| 날짜 구분 | 가운데 `hairline` + `caption` |
