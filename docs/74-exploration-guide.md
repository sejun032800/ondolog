# 74 탐방 안내 한 장 (앱을 쓰는 순서)

> 기기: Android만. 틀: `docs/51-device-checklist.md` 49항목(U0 + U0b + B 27 + C 13 + D 7)을 **앱을 쓰는 순서**로 다시 놓았다. 항목 번호는 51 문서와 같다. 항목마다 "누르는 것 -> 이러면 정상".
> **계정 준비 뒤** = 두 번째 계정(두 번째 기기 또는 다른 카카오 계정)이 있어야 하는 항목(51 문서의 ②). 없으면 결과에 "기기 대기"라고 적는다.
> 그 밖에 74- 작업에서 "실기기에서 확인"으로 남긴 것은 맨 아래 **추가 확인**에 모았다(항목 이름 앞에 `+`).
> 기록 방법: 항목마다 O / X. X면 캡처 파일 이름 + 재현 한 줄. 시험용 카카오 계정만 쓴다(실제 커플 계정 금지).

## 맨 위 두 줄

1. **처음부터 다시 하는 법**: (저장소 루트 PowerShell) 환경 변수가 PC에 이미 있으면 첫 두 줄은 건너뛴다. 아래를 위에서 아래로, 한 줄씩.

   환경 변수(값은 이 문서에 쓰지 않는다):

   ```
   $env:ONDOLOG_SUPABASE_URL = '<프로젝트 주소>'
   ```

   ```
   $env:ONDOLOG_SUPABASE_SERVICE_ROLE_KEY = '<서비스 키>'
   ```

   미리 보기(아무것도 지우지 않는다. 지울 목록이 맞는지 눈으로 본다):

   ```
   deno run --no-check --no-lock --unstable-sloppy-imports --config supabase/functions/deno.json --allow-env=ONDOLOG_SUPABASE_URL,ONDOLOG_SUPABASE_SERVICE_ROLE_KEY --allow-net=<프로젝트 ref>.supabase.co --allow-read=supabase/.temp/linked-project.json scripts/ops/resetTestAccount.ts <카카오 이메일>
   ```

   실제 삭제(`--apply`):

   ```
   deno run --no-check --no-lock --unstable-sloppy-imports --config supabase/functions/deno.json --allow-env=ONDOLOG_SUPABASE_URL,ONDOLOG_SUPABASE_SERVICE_ROLE_KEY --allow-net=<프로젝트 ref>.supabase.co --allow-read=supabase/.temp/linked-project.json scripts/ops/resetTestAccount.ts <카카오 이메일> --apply
   ```

   그다음 폰에서 앱을 지우고(앱 아이콘 길게 누르기 -> 삭제) 평소 하던 방법으로 다시 설치한다. 처음 화면부터 다시 시작해야 정상.

2. **녹화할 때**: 화면 녹화는 켜 두되, **카카오 로그인 화면**(아이디 · 비밀번호 칸)과 **공유 시트의 연락처 목록**은 녹화에서 뺀다(그 순간만 녹화를 멈추거나, 나중에 그 구간을 잘라 낸다).

| B20 뒷부분 | 다시 끝까지 가서 동의 후 [카카오 로그인]을 누른다. 카카오 화면에서 앱을 닫고 다시 열기도 해 본다 | 로그인 뒤 앱으로 돌아와 다음 화면이 열린다. 도중에 닫았다면 로그인 화면 근처에서 다시 이어 간다 | |

| C3 | 커플 전용 기능(채팅 · 피드의 기록 버튼 · 매거진 · 메인 연결 블록)을 누른다. **I01 화면을 캡처** | 초대 안내가 한 번 뜬다. 닫은 뒤 다시 저절로 뜨지 않는다 | |
| B17 | 연결 전에 채팅 탭을 누른다. 안내 카드의 버튼을 누른다 | 화면 안 카드가 보이고 시트가 저절로 뜨지 않는다. 버튼을 누르면 바로 초대 코드 화면으로 간다. 코드 발급 · 공유가 된다 | |
| C7 | 연결 전 피드 탭을 연다. **I04 캡처** | 빈 상태 안내와 버튼 위치가 보드와 같다 | |
| + 안전 영역 (B10) | 피드 · 서재 · 설정 화면을 위로 길게 스크롤한다 | 내용이 맨 위 상태 표시줄 아래로 비쳐 보이지 않는다 | |
